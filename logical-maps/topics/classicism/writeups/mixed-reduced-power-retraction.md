# Mathematical Possibilism with incomplete proposition algebra

This variation gives one point satisfying Mathematical Possibilism, Functional Choice and Gallin Extensional Comprehension, at which Countable Boolean Completeness, Inextensible Comprehension, the Barcan Formula and Arithmetic Necessitism all fail. Both canonical rigid powers hold necessarily. Work in ZFC.

## Indices and the admissible ultrafilters

Use the [reduced-power retraction](reduced-power-retraction.html) with its singleton individual domain at $r$, its two-element individual domain at $s$, and its maps $jh_i=1$. Split the countable entrance index set into two infinite parts $A,B$. Use the ideal $J$ consisting of finite subsets of $B$. At every relational type the root data are a current row and a sequence of target rows modulo equality away from a set in $J$. Thus an entire row at any index of $A$ is observable. At each entrance take any ultrafilter disjoint from $J$, chosen separately for every outer index as in the original model. This includes principal ultrafilters on $A$ and the free ultrafilters concentrated on $B$.

The term and identity proofs of the reduced-power model apply with this ideal. Each representative agrees on every $A$-index and all but finitely many $B$-indices with every other representative. Finite unions of exceptional sets still belong to $J$, including in the abstraction calculation for entire rows of newly bound arguments. Two nonidentical entrance components disagree on an $A$-index or on infinitely many $B$-indices. Choose its principal ultrafilter in the former case or a free ultrafilter containing the discrepancy in the latter. The Fubini construction at arbitrary outer indices then separates whole entities. The deterministic return still projects onto the entire old coordinate, and Łoś computes formulas at each stage from the indicated base kind.

## The ordinal bound and the missing join

At $r$ the proposition algebra is
$$
\mathbf 2\times\mathcal P(A)\times(\mathcal P(B)/\mathrm{Fin}).
$$
To bound the actual inexact ordinal carrier, use the [finite row-table argument](countably-many-sections.html) at $\rho=(eet)(et)t$. Let $Z$ consist of the entities whose current row is an extensional table on the input individual order and field and whose entrance sequence agrees modulo $J$ with a single fixed extensional table on the two target individuals. There are finitely many possibilities for the two tables, so finitely many such *whole entities*. Both base kinds admit every current subset. Ordinal zero and successor preserve these table conditions, since well-orderhood and its restriction to the predecessor segment depend only on the current individual extensions. If a rigid family of ordinals has actual extension contained in $Z$, persistence and weak inextensibility identify it with the finite disjunction of the haecceities of its current members. Its entrance rows are therefore the images of this same finite list except on a single $J$-small set. Each listed ordinal likewise has its fixed target table except on a $J$-small set. On all remaining indices the limit tests well-orderhood and the conjunction of those same tables on the current order and field. This proves closure of $Z$ under rigid limits and finiteness of the actual ordinal benchmark.

All current subsets and coding graphs are available. Every infinite current carrier contains a countably infinite subset larger than this benchmark, power-closed because each of its strictly smaller subsets has finite size and finite power. Thus every revised-small Boolean algebra is finite. For an algebra with $k$ atoms choose $k$ points of $A$; the principal interval below that finite set in the middle factor is isomorphic to the algebra. Mathematical Possibilism follows at all carrier types.

Partition $B$ into countably many infinite blocks. Their classes in the last factor have no join, since one can remove a point in each block from any upper bound while leaving it an upper bound. By full current rows there is a property selecting these propositions and an injection into the standard Frege numerals counted at $t$. Countable Boolean Completeness and Boolean Completeness at $t$ both fail. The same factor supplies a nonzero proposition with no atom below it.

## Choice, rigidity and infinity

Every selected output at the root may still be spliced on the input slices $h_ix$, so Functional Choice holds. For Gallin Extensional Comprehension realize a current row $R$ with constant entrance row $j^{-1}[R]$. At an $r$-to-$s$ step the membership of every transported tuple is unchanged by $jh_i=1$; at an $s$-to-$r$ step membership agrees by the definition of the entrance row. The same equality transfers through arbitrary outer indices by Łoś. Both the relation and its complement are persistent. As before the tester containing just the $h_i$-images in the entrance rows refutes Barcan at every input type.

The [finite bounds and return classification](reduced-power-retraction.html) remain valid. An infinite weakly rigid root relation puts each old member in its entrance row almost everywhere, in particular cofinitely on $B$. The diagonal tester from that subfamily excludes a sequence of distinct old tuples transported to $B$-indices; give it full rows on $A$. Every old member still passes necessarily but a free ultrafilter concentrated on $B$ witnesses the violation. For a fully inextensible relation, the return requires the whole root row to be covered by the projection of its entrance on cofinitely many $B$-indices. The same diagonal deleting a single lift of each of a list of distinct members works entirely on $B$. Precisely finite root extensions have inextensible coextensions; thus Inextensible Comprehension fails. Weakly Inextensible Comprehension holds necessarily via a current row with bottom entrance or return coordinate.

At $s$, weakly rigid relations still have a rigid return coordinate whose finite current extension is exactly the projection of their current extension at $s$. The lift of a return tester uses full current row and is unaffected by $J$. Every weakly rigid subrelation of a later image of that finite return relation lifts by choosing the corresponding return members and their preimages in the current $s$-row. This gives Tame Rigidity and both canonical powers at both bases and hence necessarily, as in the original classification.

Both base proposition carriers are infinite and contain enough entities for a real number structure. The current Frege numbers consist of exactly the standard numeral denotations, by the full current predicate extensions. Thus the Peano guard at $t$ holds throughout, but its actual infinite number row cannot be weakly rigid. Also every actual real number structure has an infinite number row, and an actual real structure at $t$ is realized by full current rows. Arithmetic Necessitism and both Analytic Necessitisms fail. In contrast the guarded sentence-level arithmetic and second-order analytical theories are fixed at both base kinds and at their Łoś stages.

The current-only true propositional atom remains strong at both base kinds. The self-atoms and two-hat necessity proofs in the original model apply with the enlarged class of entrance ultrafilters: any nonzero entrance support can be observed at some admissible entrance, where both that current component and the return component are nonzero. At odd stages a true current-only atom becomes impossible under the mandatory return, whereas any original truth holds at every even diagonal return. Thus necessarily every self-atom is strong at every relational type, and necessarily all truths are two-hat necessary. There are now further propositional atoms. A singleton at an $A$-index is an atom; at its principal entrance it is true and has nonzero return component, so it is not an atom there. This refutes Atoms-are-Self-atoms at $t$.

For the one-proposition signature choose a root denotation outside the countably many pure term denotations and transport it along the histories. For modal well-ordering select a well-order of each sort at each of $r,s$ and use the same target well-order at all entrance indices. All later stages satisfy the well-order sentence by Łoś. Individual domains always have size one or two.

# Local Modal B and the Barcan formula

At a point, Modal B is equivalent to the assertion that distinctness-preserving necessity entails ordinary necessity for every proposition. If a true $q$ witnesses $\Box_{\ne}p$, B gives $\Box\Diamond q$. The witness supplies $\Box(\Diamond q\to p)$, so $\Box p$. Conversely, for any true $q$ the very same $q$ witnesses $\Box_{\ne}\Diamond q$. The asserted entailment now gives $\Box\Diamond q$, the instance of B.

Consequently if also $\Box_5p\to\Box_{\ne}p$ for each current $p$, all three operators agree at that point. For an admitted $F^{\sigma t}$, ordinary necessity of $F(x)$ for every current $x$ implies 5-necessity of each $F(x)$. The Barcan formula for $\Box_5$ then gives $\Box_5(\forall x\,F(x))$. The local agreement gives $\Box(\forall x\,F(x))$. This proves the Barcan formula at every input type $\sigma$. [The Barcan formula for 5-necessity](../index.html#background/varieties/box5-barcan)

C proves the equivalence of B and ND at type $t$. Plenitude entails ND, and Functional Choice entails Plenitude. Each can therefore replace B in this result. Neither premise requires an outer box.

# Self-atoms at the split return stages

In both [the supported-stage Functional Choice model](functional-choice-over-supported-stages.html) and [the split root before the integer stages](split-root-before-integer-stages.html), every self-atom of every relational type is strong, necessarily. Here a self-atom is a possible relation which is an atom whenever instantiated. A strong atom has an atom or bottom as its transport at *every* arrow.

## Separating the return coordinate

Write a root relation as $Y=(E,(V_b)_b)$, with $E$ its current tuple row and $V_b$ its row at the entrance $h_b$. At a nonroot object $b$ every relation has two independent parts $(A,Y)$, its ordinary profile and its whole return coordinate. The Boolean order, intersection and complement are componentwise. In particular an entity with two nonzero parts is split by its ordinary part alone.

If some $V_b$ of a root self-atom were occupied, $h_bY$ would be instantiated and have two nonzero parts: the ordinary part contains that tuple, and its return coordinate is $Y$. Hence all $V_b$ are empty. The only remaining nonempty row $E$ must be a singleton because the self-atom is instantiated at $r$, where arbitrary current subrows are available. Conversely, such a root-only singleton is a strong atom. Every direct entrance transports it to a pure return coordinate $(0,Y)$, an atom in the product order. An ordinary continuation retains this form, and a return recovers $Y$.

Now let $(A,Y)$ be a self-atom at a nonroot object with $Y\ne0$. If $A\ne0$, some ordinary arrow makes its ordinary part inhabited. Its return coordinate there is still $Y$, giving the same split at an instantiation. Therefore $A=0$. After the return $Y$ is itself a self-atom because it is nonzero and inherits the boxed condition. Its classification at $r$ now makes $(0,Y)$ strong. If $Y=0$, all resets and returns give bottom. It suffices to consider the ordinary parts on ordinary arrows.

## The ordinary components

* At a bounded partial-injection stage, no relation with an occupied identity row is an atom. Given its pin $P$ and tag cutoff $b$, use a partial identity on $P$ at two different finite tags at least $\max(b,|P|)$, with empty word. Its row at each equals its identity row, including the same chosen tuple. An admitted scalar testing equality to the first tag splits the relation. The tag test is invariant under target permutations and has a finite cutoff. A nonzero ordinary self-atom would transport to an occupied identity row somewhere in this same ordinary component, which is impossible.
* At an old paired-integer stage, choose an ordinary doublet disjoint from the countable pin of a relation with occupied identity row. Compare the identity with the empty-word map that collapses just this doublet. The two rows contain the same tuple. The scalar test that the two images coincide is pinned by the two chosen coefficient points and is target-equivariant. It splits the putative atom. The same proof applies after any ordinary arrow because it lands at another integer stage.
* At the unrestricted permutation stage $v$, all ordinary arrows are invertible. Any nonzero self-atom is an atom after an instantiating arrow, so it is an atom already, and every ordinary transport preserves atomhood.
* At the finite-support stage $u$, suppose the ordinary part has an occupied row at $ig:u\to v$. At $v$ its transport along this arrow is instantiated. Choose a nonidentity permutation fixing $g[P]$ pointwise for a finite pin $P$. The identity and this permutation give two different $v$-addresses with the same occupied row. At $v$ arbitrary single-address tests are admitted, so this transport splits. A nonzero ordinary self-atom at $u$ must therefore have only $u$-loop rows. Invertibility and target equivariance make it inhabited already at the identity. It is then an atom; the ordinary $u$-loops preserve it as an atom, and arrows to $v$ give bottom.

All arguments concern arbitrary tuple rows, including empty tuples at propositional type. They exhaust the path types and prove the boxed claim. OpenAI Codex (GPT-6), prompted by Daniel Kodsi, 27 November 2026. Two further GPT-6 researchers checked both model calculations independently.

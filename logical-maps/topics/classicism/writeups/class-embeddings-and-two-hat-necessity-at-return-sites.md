# Class embeddings and two-hat necessity at return sites

A Functional Choice root can satisfy necessary two-hat necessity of truths while both rigid powers and Relational Choice fail at an accessible point. The construction has both a one-return version with Strong Actuality and a two-return version in which Strong Actuality fails at the root. It also realizes the original root's Mathematical Possibilism, both local rigid powers, rigid comprehension, and the two forms of Analytic Necessitism. [Atomic return sites](atomic-partial-injection-and-multiset-returns.html)

Use the same auxiliary set $A$, equivalence relation $E$, tag, finite multiset, word, return equations, pin conditions and current rows as in the original model. Restrict each ordinary partial injection $f$ by requiring that $aEb$ iff $f(a)Ef(b)$ whenever both inputs are live. These maps compose and include all partial identities and all global class automorphisms. Every finite live restriction extends to a global class automorphism, by first completing the finite matching of represented classes and then completing the injections in each affected class. If a finite rank needs filling while prescribed sites remain dead, add fresh inputs and outputs in as many new classes as needed. The atom proof by saturation of the tag therefore still works. The two-pin argument against a transversal uses partial identities and class automorphisms. The rigid-power failure uses independently pinned multisets and words with all partial coefficients treated together. The remaining root proofs use only the return equations, full current rows and equivariance of the entrance labels. Thus all the original choice, atom, power and measurement arguments apply. [Proofs in the common model](atomic-partial-injection-and-multiset-returns.html)

For a site truth $p$, choose its finite partial-map pin $P$ and tag cutoff $b$. Let $q$ have no return component and hold on an ordinary arrow if its word is empty, its multiset is zero, its tag is at least $b$, and it is live on $P$. This is a true scalar. If some continuation realizes $q$, the original arrow was ordinary and already had all four properties. Resets cannot return to the ordinary sector, tag bounds take minima, and dead sites stay dead. Its coefficient on $P$ therefore agrees with a class automorphism. By pinning and left equivariance, $p$ is true at that arrow. This proves $\Box(\Diamond q\to p)$, so every site truth is ND-necessary.

At the root use its identity-only truth $a$. At an entrance, any continuation realizing the transported $a$ must be one of the returns to the root. Take the site truth $v$ holding on all ordinary arrows and having bottom at every return. Those returns make $v$ permanently impossible. Hence $a$ fails distinctness-preserving possibility at the entrance. At the identity every actual root truth holds. Thus $a$ witnesses two-hat necessity of each root truth, including in the two-return model. Together with the preceding site calculation this gives necessary two-hat necessity of truths.

In the original model, where every partial injection is allowed, the same root guard works. There the closed necessary principle fails at the sites. Choose a pair of distinct members of one class, and let $p$ require their images to be live and in one class; use bottom on resets. A unit $u$ with empty word, infinite tag, zero multiset and a permutation splitting this pair makes $p$ false. For every true source guard $q$, its transport at $u$ is distinctness-possibly true. For any true target test, use $u^{-1}$ to recover $q$ at the identity and replay $u$ to recover the target test. Thus no guard witnesses two-hat necessity of $p$ at the original site.

# Signature Possibility+, Mathematical Possibilism and failures of choice

At an isolated fixed point, signature Possibility+ and revised Mathematical Possibilism can hold together while Relational Choice and Transversal Choice fail. At a different point of the same interpretation, signature Possibility+ holds while even Transversal fails. The construction combines the [diagonal-tail symmetry](supported-diagonal-tail-permutations.html) with an exit into a [signature-definable Maximalist model](coalesced-definable-root-signature.html). A Boolean-valued component supplies intervals for internally complete algebras.

## The three coordinates of a relation

Fix a set-sized admitted free signature and take its signature-definable point $v$, satisfying signature Possibility+. Write $I=D_e(v)$. The core sites are a copy of Cantor space $C=2^\omega$ and an isolated point $\star$. The group $\Gamma$ of permutations of finite prefixes acts on $C$ in the usual way and fixes $\star$. Its subgroup $K_n$ applies the same finite-prefix tail permutation after each prefix of length $n$. The $K_n$ descend, and any $g$ acting only on prefixes of length $r$ commutes with $K_m$ for $m\ge r$. Call an element of a $\Gamma$-set smooth if some $K_n$ fixes it. A supported subset is a subset fixed as a set by some $K_n$. The core has individuals $I$ with trivial group action, and the common absorbing exit to $v$ is the identity on these individuals.

There is also a Boolean-valued component. Its individuals form a singleton, and each core individual maps to it. Its propositions are in a smooth Boolean $\Gamma$-algebra $L$ with suprema of all supported subsets; the suprema here are actual least upper bounds in $L$. Its higher relational types consist of all smooth maps from argument tuples to $L$ under the conjugation action. Equality of entities is crisp. At every type, a quantifier takes the meet or join over that component's own domain. For fixed smooth parameters the values being joined form a supported subset, since replacing arguments by their translates under a common parameter stabilizer permutes the range. The resulting value is smooth. No designated two-valued evaluation of $L$ is needed.

At relational type $\tau$ a core entity consists of three independent parts.

* A table on the core sites and their argument tuples, supported by some $K_n$, whose truth set in the site coordinate is clopen for each fixed tuple.
* An arbitrary whole value of type $\tau$ at $v$. The group acts trivially on this coordinate.
* A whole value of type $\tau$ in the Boolean-valued component with its given group action.

The core transports between sites are identities. Transport to the old component reads the second coordinate and then uses old transport. The third coordinate is interpreted by Boolean values as above. Application at a core site reads the core table, and application in either other coordinate uses the respective projected arguments. At intermediate relational types application produces the remaining table and both remaining values in the same way. Each relational constant receives its designated old value and, for example, constant top tables and terminal values. Individual names have their old denotations in the core.

For term closure the support of a finite tuple of core parameters suffices. In particular, an existential quantifier over core arguments takes a union of clopen sets. The union is open and invariant under a common $K_n$. On $C$ every $K_n$-orbit is dense in its length-$n$ cylinder, since any finite prefix of a tail can be permuted into any other of the same length. An invariant open subset is therefore a union of entire length-$n$ cylinders: its closed invariant complement contains the orbit closure of each of its points. Thus the union is clopen, also on the isolated point. Abstraction in the other two coordinates uses their own arguments, including any arguments which have no specified root preimage. Core equality of whole entities is detected by the supported singleton tester of the entity in question, with a constant core row and arbitrary other coordinates. The box at a core site tests equality of the entire proposition to top, so its core row is all sites or no sites according to this test. Its two other values are the boxes in their own interpretations. An H-theorem of equivalence gives identical core truth sets at all arguments, identical abstractions in the old interpretation and equal Boolean values at every terminal tuple. Hence its abstractions are identical as full triples, as required for Logical Equivalence in C. The other H axioms and inference rules follow by the same componentwise evaluation, with Boolean value one for theorems in the terminal. This uses the full-function Boolean semantics only for smooth maps and supported meets. [Bacon's Boolean-valued semantics](full-boolean-valued-atom-and-atomless.html)

At any core point, every eligible assignment for signature Possibility+ keeps the same individual values and named individuals in the old projection. The old possible witness still witnesses the required possibility at the core, since a proposition possible at $v$ has a nonbottom old coordinate. This includes signature Maximalism. The simple Cantor counterexample to Transversal below would already work with a trivial Boolean component.

## A uniform bound on the inexact ordinals at the fixed point

Write $\rho=(eet)(et)t$. The following class $Z$ has cardinality bounded independently of $L$. A core $\rho$-entity in $Z$ uses, at every core site, one common function of the current order and field extensions on $I$. Its old value is arbitrary. Its terminal value must be a Boolean polynomial in the two Boolean inputs consisting of the order at the unique pair and the field at the unique individual, using just the constants 0 and 1. There are at most sixteen such polynomial functions. Every member of $Z$ is fixed by the entire group, including in its core table: the action on individuals is trivial and the same function of the two extensions is used at every site. Thus
$$
  |Z|\ \le\ 2^{|\mathcal P(I^2)\times\mathcal P(I)|}\,|D_\rho(v)|\,16.
$$
At $\star$ membership in $Z$ is an admitted current test by its constant core row.

Zero belongs to $Z$. Every subset of $I$ is represented at every core site by a constant core row, so well-orderhood there is the ordinary test on the order and field. At the one-individual terminal, well-orderhood has the same finite truth table on the two input bits, interpreted as a Boolean polynomial. Indeed on each of the four Boolean pieces where those inputs have prescribed classical truth values, every possible subfield of the singleton either excludes or includes its member, with the two crisp possibilities available. Successor restricts the order and field to an initial segment at a cut point. This operation is extensional in the core, and on the singleton its restriction and test are again Boolean polynomials in the two inputs.

For a rigid family $Y$ whose actual members all belong to $Z$, use a tester with the constant core row $Y_\star$ and top at the other two coordinates. This tester is admitted because $\star$ is fixed. It necessarily accepts every actual member. Weak inextensibility bounds every core row by $Y_\star$, and persistence puts every actual member in every core row. Thus the limit uses the same set of extensional tables at every site. The terminal values of the actual members belong to a finite set $S$ of Boolean polynomial functions. Use a second tester with top core and old values, and the finite disjunction of crisp identities to members of $S$ at the terminal. Persistence gives terminal membership value one for each member of $S$; weak inextensibility gives zero for each other terminal entity. The terminal limit therefore uses a finite meet of Boolean polynomial values together with well-orderhood and remains a polynomial of the required kind. This proves closure of $Z$ under limits of rigid families. The impredicative ordinal predicate at $\star$ consequently has its entire extension $H$ in $Z$.

## The Boolean algebra of the extra component

Choose a strong limit cardinal $\mu$ of uncountable cofinality above this bound, for example by iterating the power-set cardinal operation for $\omega_1$ stages above the bound. For each $n$ and up to isomorphism take all nontrivial Boolean algebras $B$ of cardinality below $\mu$ with a $K_n$-action by automorphisms for which the following hold.

1. Each element is fixed by some $K_m$ for $m\ge n$.
2. Every subset invariant under some such $K_m$ has a supremum in $B$.

These algebras and actions can be chosen from a set. Extend $B$ to an algebra over the coset set $\Gamma/K_n$ by taking sections of the copies of $B$ in $\Gamma\times_{K_n}B$ with pointwise Boolean operations and the induced action on sections. Use its smooth elements. For a smooth family of sections, meaning a family invariant as a set under a common $K_j$, its projected value set in the coset $gK_n$ is invariant under a sufficiently deep $K_l$ after identification with $B$: take $l\ge n,j$ and larger than the prefix level where $g$ acts. That subgroup fixes the coset and commutes with $g$, and the second condition supplies a supremum. Coordinatewise suprema give a supremum section. It is fixed by $K_j$ by uniqueness, and is therefore smooth. The section equal to one just at $K_n$ and zero elsewhere is fixed by $K_n$. Its entire lower interval consists of the sections on this one coset with arbitrary value in $B$, and the identification with $B$ commutes with $K_n$. Take $L$ to be the smooth elements in the product of all these section algebras, acting diagonally. The same coordinatewise proof gives the required suprema of all supported families in $L$. Each distinguished interval remains an interval by using bottom in the other factors.

Now consider a Boolean algebra admitted as complete and small at $\star$. Its carrier and order in current extension are invariant under some $K_n$. Every $K_m$-invariant subset of the carrier for $m\ge n$ has a constant core membership table, hence is an admitted family. Completeness supplies its actual supremum. All elements are smooth, so the carrier is the countable union of its sets of elements fixed by the $K_m$ for $m\ge n$. If its size were at least $\mu$, one of those sets would contain a set $Y$ of size $\mu$, because $\mu$ has uncountable cofinality. All subsets of that $Y$ and all comparison graphs between $Y$ and $H$ are supported, since $Y$ is pointwise fixed by one $K_m$ and $H$ pointwise fixed by $\Gamma$. The current comparison therefore puts $H$ strictly below $Y$. Every $A\subseteq Y$ of smaller cardinality has $2^{|A|}<\mu$, and that many elements of $Y$ can code its subsets using a supported membership graph. These external cardinal comparisons also give the internal comparisons on subcollections of this pointwise fixed $Y$. This contradicts smallness.

The algebra thus has cardinality below $\mu$ and its transferred $K_n$-action appears in the list defining $L$. At the core take the proposition whose core and old values are bottom and whose terminal value is the distinguished unit for this factor and coset. Propositional entailment below it is exactly the ground order on that terminal interval, because the terminal box tests equality with top. Its interval is the given algebra. The isomorphism graph in current extension is $K_n$-invariant and so is represented by a constant core table. Bottom covers the trivial algebra. This proves revised Mathematical Possibilism at $\star$.

## The choice failures

At $\star$ the proposition true only there and bottom in both other coordinates is a true strong atom. To refute Transversal Choice, take the core Cantor clopen propositions with bottom old and Boolean coordinates, and pair each with its complement relative to the Cantor component. All other propositions have singleton equivalence classes. This is an admitted invariant equivalence. A putative transversal has current row invariant under some $K_n$. Flipping the next bit exchanges the two halves testing that bit, and hence the two members of one of the classes. It cannot select exactly one. Relational Choice also fails. For each unordered pair above take the property having that pair as a constant core row, bottom elsewhere. Ask for a member of the pair on these inputs and allow all outputs on other inputs. The serial relation has an invariant constant core table. The same tail flip fixes its input and interchanges its only eligible outputs.

At $u=0^\omega$ in $C$, take the serial relation on propositions requiring a proper currently true subpart whenever such a subpart exists, allowing any output otherwise. Suppose a selector is supported by $K_n$. Apply it at $u$ to the length-$n$ cylinder containing $u$, with the other coordinates bottom. A deeper cylinder is a proper true subpart, so the selected $q$ is a proper true subpart. Its old and Boolean values must both be bottom. The group $K_n\cap\operatorname{Stab}(u)$ fixes the selector, $u$ and the input, so fixes $q$. Within that cylinder, the orbit of every other point under this subgroup is dense, since any sufficiently long nonzero tail prefix can be permuted to any other while fixing the all-zero prefix. Consequently its only invariant clopen parts are the empty set and the whole cylinder. This contradicts the requirement on $q$.

Transversal itself fails at $u$. For a finite-prefix permutation $g$, let the property $F_g$ of propositions have core value at site $x\in C$ equal to the test that $g(x)$ belongs to the argument's core clopen. Give it empty row at $\star$ and bottom elsewhere. This is supported by every sufficiently deep tail group. If a selector of coextension classes is fixed by $K_n$, take $g$ to flip bit $n+1$ and $z=g(u)$. Its unique selected representative $Y$ for $F_g$ at $u$ satisfies $Y(p)$ there iff $z$ belongs to the core clopen of $p$. Every element of $K_n$ fixing $u$ and $z$ fixes $Y$ as a whole entity, by uniqueness. Choose $m>n$ with $K_m$ fixing $Y$. Let $k$ flip bit $m+1$, and let $l\in K_n$ exchange two sufficiently long tail prefixes, fixing $u,z,k(u)$ and moving $k(z)$. These four tail prefixes can be distinguished using bits $n+1,m+1$. Then $k^{-1}lk$ fixes $u,Y$ and moves $z$, contrary to the characterization of $Y$ on Cantor clopens with bottom other coordinates. This is the conjugation argument of the [original diagonal-tail example](supported-diagonal-tail-permutations.html), applied to the enlarged typed domains.

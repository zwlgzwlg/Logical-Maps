# Paired sites with unrestricted Barcan

Both models have signature Possibility+ and Barcan at every type. In each, a 5-necessity fails to be two-hat necessary and a two-hat necessity fails to be ND-necessary. At the evaluation point of the first model all propositions are atomless in the sense that every nonzero proposition has a proper nonzero part. In the second model revised Mathematical Possibilism holds and every relational atom is strong.

## Domains and evaluation point

Use the four core objects of the [paired-site construction](stone-terminals-paired-sites.html). Each coordinate consists of countably many doublets, with or without one extra singleton block. All block-preserving maps are allowed, including those collapsing a doublet. Evaluate at the object with a singleton in the second coordinate only. Use one public proposition name. For the old pointed model take [Dorr's pinned substitution root](coalesced-pinned-substitutions-root.html) $K,w$ for this signature. It satisfies signature Possibility+ and Barcan at every type. All core objects use its individual domain, with identity core transport. Individuals are distinct from the sites supporting the relational tables.

From every core object add an absorbing entrance to each of a Cantor space $C$ of copies of $K,w$, acting identically on individuals. In the second model also add the independent one-individual Stone terminals $X$ of the paired-site construction. At a core object a relational entity has the usual finitely pinned table of core rows, a locally constant section $C\to D_\tau(w)$ of *whole old entities* into the discrete domain, and, when present, its locally constant Stone-terminal section. All three parts are independent. Core arrows fix the sections and precompose the table. An old entrance evaluates the section at its label, and a further old arrow acts on that value. At the Stone terminals individuals have their unique possible value. Give the public name its old value throughout $C$, constant core rows and a constant Stone section.

Transport respects composition. A finite pin of the core table determines the transport of the entire entity to any specified core target. Term closure on the core uses a common pin for the parameters. Evaluating a term at an old entrance depends only on the tuple of whole parameter values at its label, locally constant in identical copies of the same pointed model. The same argument applies on $X$. This gives abstraction, including matrices quantifying over higher types, by induction on terms. All current tuple sets are admitted by a table depending only on the target. In particular external well-orders have current representing graphs. Each old entrance preserves the individual tuple and public signature interpretation used to witness signature Possibility+.

## Lifting witnesses for Barcan

Fix a root property $F$ and a witness $y$ for it at some arrow. For a core arrow $h:s\to v$, enlarge a pin $P$ of $F$ to whole blocks. Enlarge a pin $S$ of $y$ similarly. In each coordinate choose in $s$ one fresh doublet outside $P$ for each block of $S$. Choose $g:v\to s$ embedding each such block into its reserved doublet. Choose $h':s\to v$ agreeing with $h$ on $P$ and inverting these embeddings on $S$. A reserved doublet for a singleton can be collapsed to that singleton. Both partial prescriptions extend to block-preserving maps on the remaining sites. Then $h'F=hF$ and $h'g y=y$, so $g y$ is a current entity possibly satisfying $F$. For individuals the action on the core is the identity and the same argument uses the empty pin.

At an old copy with label $c$, the possible instantiation is a possible instantiation of the old property $F_c$ at $w$. Local Barcan there supplies a $w$-entity $z$ and a continuation witnessing $F_c z$. A constant $C$-section with value $z$ supplies a root representative. For an individual use $z$ itself. At a Stone terminal any relational witness lifts as a constant Stone section, and its sole individual lifts from the nonempty root domain. These cases prove the unboxed Barcan formula, including its relational and propositional restrictions.

## Splitting and strong atoms

A nonzero core-supported table has a nonempty row at an arrow $h$ and tuple $a$. Take a doublet outside its source pin and two arrows to the same target agreeing with $h$ on the pin but sending a site of that doublet to different target sites. Their rows both contain $a$. Intersect the table with the finite-pin condition that this fresh site has the first of those images. This splits the table into two nonzero parts. In the old coordinate a nonzero section is constant at a nonzero whole entity on some nonempty clopen patch. Split that patch into two nonempty clopens. The same argument works when the value is first instantiated strictly beyond the old entrance.

In the model without $X$, these two splittings exclude every atom. With $X$, an atom must therefore live entirely in the Stone coordinate. There an atom at relational type is a single tuple over a single isolated point: any two points of a nonempty clopen support can be separated by a clopen, and the terminal tuple sets are finite and discrete. Core transport preserves that atom, old entrances take it to bottom and each Stone entrance takes it to bottom or a singleton atom. Thus every atom is strong at the root. In the Stone version the unit of the atomless complete regular-open Cantor algebra factor remains a scalar self-atom with no atom below it, as in the original construction.

In both models the old-coordinate Cantor algebra also gives a family with no join. Use top old sections on the disjoint cylinders $0^{2n}1$ and bottom elsewhere, with other coordinates bottom. This family is a current property. An upper bound takes the old top at the all-zero sequence and, by local constancy, on a neighbourhood of it. One can strictly reduce it on a sufficiently late odd cylinder. Thus propositional Boolean Completeness fails.

## Modal separation and the ordinal bound

The two separating propositions, the tests and the restorative core arrows are exactly those in the [paired-site proof](stone-terminals-paired-sites.html). The guard requiring an endomorphism to fix finitely many sites is false at every exit. Both separating propositions and the upper-type test in the 5-necessity argument have value top at every exit. All sections used here are constant. An arbitrary test in the reverse direction still has a finite core pin, so both failures persist.

For the version with $X$, use the same inexact ordinal bound with the old section arbitrary. The core tester for the rigid limit has value top at every old entrance. The terminal tester has constant old value top as well. Thus the old-coordinate change preserves the two closure arguments. For $\rho$ the type of inexact ordinals the old coordinate contributes at most $|D_\rho(w)|^{|C|}$ to the cardinal bound. Choose the strong limit cardinal above the resulting product before constructing $X$. The separate Stone factor then represents each revised-small complete algebra by a principal interval, by the original proof.

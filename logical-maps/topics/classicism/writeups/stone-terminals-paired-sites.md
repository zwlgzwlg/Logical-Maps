# Paired sites with signature Possibility+ and Mathematical Possibilism

At the same point of a model of C, signature Possibility+ and revised Mathematical Possibilism hold, a 5-necessity fails to be two-hat necessary, and a two-hat necessity fails to be distinctness-preservingly necessary. The construction attaches absorbing exits to two independent copies of [Dorr's paired-site construction](paired-individuals-two-object.html). The pairing acts on sites used to support profiles. The object-language individuals can therefore be held fixed on the core and transported identically into a signature-Maximalist model. We work in ZFC.

## The action model

Let $W$ consist of countably many disjoint pairs, and let $V$ be $W$ with one additional singleton block. The four core objects are ordered pairs of members of $\{W,V\}$. A core arrow consists of two functions on the corresponding site sets, each sending a block into a block. Composition is ordinary coordinatewise composition. Evaluate at $s=(W,V)$. Sites in different coordinates are distinguished by their coordinate tags.

Use the signature with one propositional name $c$. Let $K,w$ be the [signature-definable coalesced root](coalesced-definable-root-signature.html) with its one individual. The construction also works for other set-sized free signatures by taking their signature-definable root and its own individual set. At every core object the individuals are $D_e(w)$ and core arrows act identically on them. From each core object $v$ add a distinguished entrance $j_v$ to $w$, acting identically on individuals, and all its composites with old arrows. Require $j_{v'}h=j_v$ for every $h:v\to v'$. For every $x$ in the Stone space $X$ specified below, add an entrance from every core object to the full one-world model with a single individual at $x$, again absorbing core precomposition. Each individual goes to the sole individual there. The exits have no returns to the core. The old domains and arrows out of every old object are unchanged.

Define the remaining domains inductively. At a core object $v$ an entity of relational type $\tau=\sigma_1\ldots\sigma_n t$ consists of three independent parts.

1. At each core arrow $h:v\to v'$ take a row on the tuples of the argument types at $v'$. The entire table must have a finite pin $S$ of source sites. Thus $h,h'$ with the same target that agree on $S$ have identical rows. For $n=0$ a row is a truth value.
2. Choose any whole entity in $D_\tau(w)$ as the value at the old entrance.
3. Choose any locally constant map $X\to F_\tau$ as the terminal section. Here $F_\tau$ is the finite discrete domain of the full one-world one-individual model at type $\tau$.

Core transport precomposes the core table and leaves the exit coordinates fixed. Exit transport reads the corresponding coordinate. Subsequent old arrows transport the chosen whole old value. A core arrow $h$ sends any pin $S$ to a pin $h[S]$ for the transported profile. If two core arrows with the same target agree on $S$, they transport the entire entity equally, by comparing composites and using absorption at exits. Indeed every individual has empty pin. Give each relational name its old interpretation at the old entrance, a constant core table and a homogeneous terminal interpretation. Individual names, if present, are the individuals they denote at $w$. A rooted unfolding can be used to display these named interpretations as global sections.

The ordinary induction on terms gives term closure. For abstraction, its row comprises exactly the tuples satisfying the matrix at the target on the transported parameters. A common finite pin of those parameters pins the core table. At the old entrance evaluate the term in the old model. At the terminals its value is a function of the locally constant finite tuple of parameter values in identical full models, so is locally constant. This includes quantification over the whole target domain. Equality of relational entities is agreement on all continuation rows and their tuples. Thus the action semantics validates C. Every current extension is admitted, by choosing it as the row on every core arrow into the current target and choosing empty rows elsewhere.

Every eligible tuple of current individuals remains eligible at $w$, with precisely the same named individuals. The possible witnesses supplied by signature Possibility+ at $w$ remain possible by composition. This proves signature Possibility+, including the empty-tuple instances of signature Maximalism.

## The two strict implications

We use $\hat{\hat\Box}P\leftrightarrow\exists q\,(q\land\Box(\Diamond_{\ne}q\to P))$. At an arrow $h$, $\Diamond_{\ne}q$ says that for every true proposition $r$ at its target there are continuations $v,x$ such that $q$ holds at $vh$ and $r$ holds at $xv$.

Let $P$ hold at every exit and its continuations, and on precisely the core arrows whose first target coordinate is $W$. At the inclusion $u:(W,V)\to(V,V)$, identity on the second coordinate, $P$ fails. For any true $q$ at the source and true $r$ at the target choose a first-coordinate pair $B$ avoiding a finite pin for $r$. Return along $v$ which fixes ordinary sites and sends the new singleton to a member of $B$. Continue along $x$ which collapses $B$ onto the singleton and fixes the other ordinary sites. Use identities on the second coordinate. Then $vu=1$ and $xv$ fixes the pin, including the singleton if present. Hence $\Diamond_{\ne}q$ at $u$, so $\hat{\hat\Box}P$ fails.

Define a root property $Y$ of propositions. Its exit values are top. Its row on a core arrow contains every proposition if the first target coordinate is $W$. Otherwise it contains those propositions admitting a pin omitting the first-coordinate singleton. The target alone determines these rows. At each target with first coordinate $V$, the proposition consisting of the endomorphisms fixing that singleton (false at all exits) admits no pin omitting it, since the identity and an endomorphism moving just the singleton agree on such a pin. Consequently $(\forall z\,Yz)=P$ as entities.

For any $z$ at the root choose a finite pin $S$ and enlarge it by adding the partners of its first-coordinate sites, forming $N$. Let $q$ consist of the root endomorphisms fixing $N$ pointwise, with all exits false. If $\Diamond_{\ne}q$ holds at $h$, then $\Diamond q$ holds there. Some $vh$ is a core endomorphism fixing $N$. Thus $h$ is core and injective on $N$. No first-coordinate member of $S$ can map to the singleton, because its distinct partner would also have to map there. The set $h[S]$ pins $h\cdot z$, so $Yz$ holds at $h$. Hence $\hat{\hat\Box}(Yz)$ and therefore $\Box_5(Yz)$ hold for each current $z$. By the C theorem giving the Barcan formula for $\Box_5$, $\Box_5\forall z\,Yz$, i.e. $\Box_5P$.

Let $T$ hold at every exit and its continuations and at precisely the core arrows with second target coordinate $V$. Write $a$ for that coordinate's root singleton. Use as guard $q$ the core root endomorphisms fixing $a$, false at exits. At any $h$ where $T$ fails, $b=h(a)$ is in a pair with mate $b'$. The true target test $r$ requires an endomorphism fixing $b,b'$. Any $v$ with $q$ true at $vh$ must send $b$ to $a$ and hence collapse $b,b'$ to $a$. No $xv$ can satisfy $r$. Thus $\Diamond_{\ne}q$ fails at every such $h$, proving $\hat{\hat\Box}T$.

For any true $r$ at the root, choose a second-coordinate pair $B$ outside a pin for $r$. Let $h:(W,V)\to(W,W)$ fix ordinary sites and send $a$ to one member of $B$. Return by collapsing $B$ to $a$ and fixing the other ordinary sites. These arrows are identities on the first coordinate. The composite fixes the pin and $a$. Thus $\Diamond r$ holds at $h$ and $T$ fails there. No true guard witnesses $\Box_{\ne}T$, by $\Box_{\ne}T\leftrightarrow\exists r\,(r\land\Box(\Diamond r\to T))$.

## The inexact ordinal bound

The following extends the [Stone-terminal ordinal bound](stone-terminal-maximalist.html) from unrestricted root loop tables to the supported core. Set $\rho=(e\to e\to t)\to(e\to t)\to t$. For each core object $v$, let $Z_v$ be the set of its $\rho$-entities such that at every core arrow their application depends only on the current extensions of their order and field arguments, and their terminal section is constant. There is no restriction on their old value. The condition is stable under core transport, since the core rows of a transport are rows at composites and its terminal section is unchanged.

Fix $v$. Its current domain admits $Z_v$ as the extension of a predicate. For the impredicative inexact Ordinal predicate this extension contains zero and is closed under successor. Indeed current well-orderhood depends only on the extensions of the order and field, since all current subsets are available at the target. Given a cut point, the current initial-segment relation and restricted field depend only on those same extensions. At identical full terminals zero is identical, and successor preserves constant values.

For the limit clause suppose $Y$ is rigid and all its current members lie in $Z_v$. Define a tester whose row on a core arrow $h:v\to v'$ is $Z_{v'}$, and whose old and terminal values are top. This table has empty pin. Each current $Y$-member necessarily passes the test by transport stability. Inextensibility gives $Y_h\subseteq Z_{v'}$ for every such $h$, including members without a current preimage. Hence in computing the limit at $h$, both well-orderhood and the applications of all the local $Y$-members depend only on current order and field extensions. Separately, let $S\subseteq F_\rho$ consist of the terminal values of current $Y$-members, each of which has constant section. Use a tester full on the core and at the old entrance and having constant terminal predicate $S$. Inextensibility puts the terminal members of $Y$ in $S$, and persistence realizes every member of $S$ at every terminal. Thus the terminal extensions of $Y$ are identical and its limit has constant terminal section. This proves closure under limits of rigid families, so the current inexact ordinals lie in $Z_v$.

Write $I=D_e(w)$ and let $A_v$ be the set of core arrows from $v$. There are at most $B=2^{|\mathcal P(I^2)\times\mathcal P(I)|}$ admissible choices for each extension-invariant core row. Therefore $|Z_v|\le B^{|A_v|}|D_\rho(w)||F_\rho|$, a bound independent of $X$.

Choose a strong limit cardinal $\mu$ larger than these bounds and $\aleph_0$. Let $L$ be the product of representatives of all nontrivial complete Boolean algebras of size below $\mu$ and $X$ its Stone space. Full current extensions and relation graphs give the usual external injections and comparisons. Any carrier of size at least $\mu$ has a subcollection $Y$ of size $\mu$ exceeding the inexact ordinal benchmark. For every smaller $A\subseteq Y$, choose $2^{|A|}<\mu$ distinct elements of $Y$ to code its subsets, with the membership relation as the admitted coding graph. Thus $Y$ is power-closed, so every revised-small Boolean algebra has size below $\mu$. Current fullness also makes any current CBA externally complete.

The root proposition order is the product of its finite-pinned Boolean algebra of core arrow tables, the old proposition order, and $\mathrm{Clop}(X)\cong L$. Necessitation tests all three parts, and each combination is admitted. For a nontrivial small CBA choose its factor in $L$. The unit of that factor, with bottom in every other factor and in the core and old coordinates, has its principal lower interval isomorphic to the given algebra. For the trivial algebra use bottom. The graph of each isomorphism is an admitted current relation. This proves revised Mathematical Possibilism at every carrier type.

The [Stone-terminal argument](stone-terminal-maximalist.html) also applies to the atomless complete factor of regular opens of Cantor space. Its isolated unit has no atom below it and is a self-atom, since at every arrow where it is true it is the top proposition of a two-valued terminal. An external well-order of an arbitrary current domain has an admitted current graph. Finally the old signature-definable point lacks a propositional join. Its principal interval in the new order is obtained by taking core and terminal coordinates bottom. The image of the offending family is an admitted current property and a supremum would have to be in that interval. Hence propositional Boolean Completeness fails.

## One paired coordinate evaluated with its singleton present

A second model uses only the two core stages $W,V$ and evaluates at $V$. Restrict the core arrows to fix an ordinary pair pointwise or collapse it to one point. A singleton may have any image in its target. The restriction is closed under composition, and every one-coordinate return used below belongs to it. Keep the absorbing old and Stone entrances, root individual carrier, signature interpretation and supported profile construction exactly as above. The proofs of C, signature Possibility+, Mathematical Possibilism, current well-ordering and the Stone and old-interval conclusions use only the supported core and the absorbing exits; they apply unchanged.

At $V$, let $p$ be any truth. A finite site pin for its core table can be enlarged to $N$ containing the distinguished singleton $a$ and both sites in each ordinary pair it meets. Use as a true guard $q$ the endomorphisms of $V$ fixing $N$, with every exit false. If $\Diamond_{\ne}q$ holds at $h$, some return brings $h$ to $q$, so $h$ is a core arrow injective on $N$. Every ordinary pair in $N$ is then fixed pointwise. If $h(a)$ is an ordinary $b$, test its target with the true endomorphism test requiring $b$ and its mate to be fixed. Any return bringing $h$ to $q$ collapses the pair to $a$, after which no arrow can fix both sites in the composite. This contradicts $\Diamond_{\ne}q$. Hence $h$ ends at $V$ with $h(a)=a$ and fixes the pin of $p$. Thus $p$ holds there. This proves two-hat necessity of every current truth.

Let $T$ hold at all exits and at the core arrows ending at $V$. It is true at $V$, hence two-hat and 5-necessary there. For any true putative ND guard choose a pair outside its pin. Go to $W$ by fixing all ordinary sites and sending $a$ to a member of this pair. Return by collapsing the pair to $a$ and fixing all other ordinary sites. The composite fixes the pin and so the guard is possible at the first step although $T$ is false there. This refutes ND-necessity of $T$. In particular signature Possibility+ and the two-hat necessity of every truth together fail to imply that 5-necessities are ND-necessary.

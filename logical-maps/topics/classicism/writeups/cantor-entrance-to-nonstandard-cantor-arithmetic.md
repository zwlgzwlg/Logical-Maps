# An atomless entrance to nonstandard Cantor arithmetic

Necessary Atomlessness, Barcan, both rigid powers, and both rigidity predicates can hold together with necessary Infinity at propositional type and disagreement on the arithmetic of that type. The component at the entrance also has no atoms at any relational type. Its distinct modes of arithmetic require only one proper entrance. [The one-component arithmetic construction](one-nonstandard-arithmetic-terminal.html)

## Two groups of loops

Work in ZFC. Fix the sign of CH of the ambient universe and let $T$ be Zermelo set theory with Choice and that sign of CH. This recursive theory has a model in the ambient universe, namely its $V_{\omega+\omega}$. By Gödel's second incompleteness theorem and completeness, take an externally countable $M\models T+\neg\operatorname{Con}(T)$. Use its internal finite-type interpretations only at standard syntactic types. It can be externally ill-founded. [Arithmetic components with fixed CH](fixed-ch-and-disagreeing-arithmetic.html)

At $s$ take the following one-object model constructed **inside** $M$. Its arrow group is $K=2^\omega$ under coordinatewise addition. The individual sort is a singleton. At relational type $\tau=\bar\sigma t$, an entity is a table on the group with values in the powerset of the current tuple carrier. Its whole row depends on some finite initial segment of the group argument. The current row is the value at the identity. Translation shifts the table. In particular every internal subset of the tuple carrier occurs as a constant table's current row. An inside-finite prefix may have nonstandard length externally. Evaluation of each standard term agrees with the evaluation calculated inside $M$, by induction on that term.

Add $r$ with the genuine Cantor group $C=2^\omega$ as its loops and a single entrance $h:r\to s$ with its distinct postcomposites $kh$, $k\in K$. Put $hg=h$ for $g\in C$. The individual sort remains a singleton. At each relational type take pairs
$$
 (L,U)\in \operatorname{LC}(C,\mathcal P(D^r_{\bar\sigma}))\times D^s_\tau,
$$
where LC takes the powerset as discrete, so one finite prefix determines the entire row. Root loops translate $L$ and fix $U$. The entrance projects to $U$. Write $\pi$ for this projection, also applied tuplewise.

For an open abstract the whole transported parameter tuple depends only on one finite prefix. Thus its satisfaction row as a function of newly supplied arguments has the same prefix bound, including in the presence of quantifiers. The second coordinate is the old abstract computed with all old arguments. This proves closure under terms and compatibility with transport. Unequal pairs differ on an argument at a core loop or at an old address. Constant first tables give every external current extension at $r$. Every arrow is onto at every type, proving necessary Barcan. For the signature take one propositional name with first table reporting that bit zero is zero and old value bottom. Translation moves its denotation and fixes every closed pure denotation, giving Independence. The name never becomes top, so even the witnessed-possibility instance asking for top fails. ## Exact images and the rigid powers

Write $E=F_1$ for the current row of a weakly rigid root relation $F=(L,U)$. Weak persistence makes $\Box F(\bar a)$ true for each $\bar a\in E$. Apply weak inextensibility to the tester $\lambda\bar x.\Box F(\bar x)$. It follows that $F\le\lambda\bar x.\Box F(\bar x)$, giving persistence of *all* members at every future. Applying each loop and its inverse now gives
$$
 L_g=g[E],\qquad U_k=k[U_1].
$$
In particular $\pi[E]\subseteq U_1$. If $b\in U_1\setminus\pi[E]$, use the root tester with full first table and old value having row the complement of $\{kb\}$ at $k$. This old table is admitted inside $M$ because the orbit map of the whole typed tuple $b$ depends on an internally finite prefix. All transports of every member of $E$ pass the test, since the old translations are bijective. The missing tuple $b$ at $h$ contradicts weak inextensibility. Thus $U_1=\pi[E]$. Conversely, exact direct images at every arrow imply both weak persistence and weak inextensibility, and the same statement after every further transport. At $s$ the same characterization follows by the two inverse loops, or directly by the same argument inside $M$. This proves necessary Tame Rigidity.

If $X\le U$ is weakly rigid at $s$, let $D=X_1$ and $E'=E\cap\pi^{-1}[D]$. Define a root relation with old coordinate $X$ and loop rows
$$
 g[E']=g[E]\cap\pi^{-1}[D].
$$
The right side is locally constant because the first factor is $L_g$ and $\pi g=\pi$. Moreover $\pi[E']=D$, so this gives a rigid root subrelation of $F$ whose projection is the entire $X$. For a subrelation at $kh$ first translate it back by $k^{-1}$. Root-loop subrelations lift by inverse root loops. Thus at every arrow the current eligible subrelations map onto all future eligible subrelations; persistence gives the opposite inclusion for both power predicates. Exactness proves their rigidity, including in arity zero. The same proof applies at $s$ by invertibility. Without a specified bound every old weakly rigid $X$ lifts by taking $E'=\pi^{-1}[X_1]$, whose loop row is constant. This proves necessary Rigid Rigidity and necessary Weakly Rigid Weak Rigidity.

## Arithmetic and analysis

At $s$ the scalar carrier is infinite inside $M$. For each internal natural $n$ the cardinality entity whose current row recognizes the properties with exactly $n$ members has the same rule at every address. Zero and successor give these entities by empty counting and deletion of one element. Internal induction and availability of their internal range as a current predicate show that the old Frege numbers at $t$ are exactly the numbers of $M$. The internal group action preserves all these pure number denotations.

At $r$, every external current subset is admitted, in particular the orbit of zero under the *standard* finite iterations of successor. This is an inductive current predicate. Each of the standard iterates belongs to every inductive current predicate and the iterates are distinct because root scalars realize finite extensions of every size. Thus the source Frege numbers are the standard naturals. The native sum and product at both points compute their ordinary local values by induction. Both points satisfy $I_t^*$ and the universal scalar property has no finite cardinality at either point. They disagree on $\mathrm{Con}(T)$. In addition a tester with full core rows and old rows omitting one nonstandard Frege number necessarily accepts every root Frege number and misses an old one. This refutes Arithmetic Necessitism directly. The pure consistency assertion with its Peano guard also witnesses the failure of pure B, since it is true at $r$ and impossible at $s$.

At the common sort $tt$, both modes have an injection of the powerset of their respective naturals into the sort by constant tables on the infinite scalar carrier. Disjoint labels for numbers and reals give a real structure there, all current relations being available in the appropriate universe. Every current real structure represents precisely that universe's natural numbers and their full powerset by the induction, completeness and extensionality clauses. Its arithmetic therefore distinguishes the two modes. All higher current graphs are also available in their respective universes, so structural CH has the same sign wherever such a structure exists. ## Atoms, choice and modal tests

Any nonzero relational table contains a tuple on a whole prefix cylinder at some loop. Splitting that cylinder on a fresh bit defines two nonzero subrelations. Apply this inside $M$ for the old coordinate, choosing a bit past its internal prefix. At $r$ either nonzero coordinate can be split independently. Atomlessness therefore holds at every type and every point. In particular the two-element Boolean algebra, which is revised-small, has no principal interval of the required size.

Choose a root well-order as a constant loop row and choose an old constant row from an internal well-order. This gives Modal Well-Ordering. More directly, a necessarily serial relation has finitely many whole loop rows; choose a functional subrelation of each one and keep the same defining prefix. Do the same internally for the independent old coordinate. The argument works at each point, giving necessary Modalized Relational Choice and Intensional Choice.

The core-only scalar, true on all root loops, is a true vicinity because a root loop can always be inverted. At $s$ take top. At $r$ the same core-only scalar witnesses ND-necessity whenever the tested proposition is true on all root loops. Conversely, there is an admitted S5 operator whose constant core row tests whether its input is true at all root loops, and whose old part makes the corresponding all-old-loops test. At either mode the operator is universal quantification over that group orbit, so it obeys N, K and B, also on every future assignment. Hence 5-necessity implies ND-necessity at both points. A scalar that depends on a root bit is true at some but not all core loops, so a true proposition fails 5-necessity at $r$.

There is a direct obstruction to Weakly Inextensible Comprehension. Let $p_i$ have core value the $i$th zero-bit test and old value bottom. The current set $A=\{p_i:i\in\omega\}$ has no open subgroup stabilizing it, since a single fresh bit flip changes exactly that member. If $Y$ were a weakly inextensible coextension, then $Y_g\subseteq g[A]$ for every root loop. Indeed, for each $d\notin A$ use the tester which has old value top and omits just $kd$ at the core loop $k$. This is an admitted locally constant table. Some open subgroup fixes the entire current row of $Y$ in the sense $Y_g=A$ on that subgroup. The inclusions for $g$ and $g^{-1}$ would make $A$ invariant under that subgroup, a contradiction.

Finally the scalar algebra lacks even a countable join. In the first Cantor coordinate take the disjoint clopen sets of sequences whose first one is in position $2i$, with bottom old coordinate. Their indicated family and an injection into the standard Frege numerals are current rows. An upper bound is true near the all-zero sequence, as it is clopen and meets every neighborhood there in a required cylinder. It can be reduced by deleting one sufficiently late odd-position first-one cylinder. Thus the family has no least upper bound.

# Mathematical Possibilism and Functional Choice without Barcan

At the designated point, revised Mathematical Possibilism, Functional Choice and Gallin Extensional Comprehension all hold. The Barcan Formula fails for each input type. Work in ZFC.

## The category and its model

Take two objects $r,s$ and generators $f_i:r\longrightarrow s$ for $i\in\mathbb N$ and $j:s\longrightarrow r$, with $jf_i=1_r$ for every $i$. The nonidentity arrows are $f_i$, $j$, and $e_i=f_ij:s\longrightarrow s$. They satisfy $e_i f_k=f_i$, $je_i=j$ and $e_ie_k=e_i$. These normal forms are distinct, since the word reductions $jf_i\mapsto1$ have no overlapping left-hand sides. The individual set at $r$ is $\{0\}$ and at $s$ it is $\{0,1\}$; each $f_i$ sends $0$ to $0$ and $j$ is constant. Take the ordinary full action model. A relational entity at an object has one freely chosen extension on target tuples for each outgoing arrow; transport precomposes the arrow index. Equality is agreement of all rows. Evaluate at $r$. ## Choosing entire outputs and refuting Barcan

Since $jf_i=1_r$, each $f_i$ is injective on every type. For any serial relation choose, for each actual input $x$, an output entity $Y_x$. At the identity put the current row of $Y_x$ in the $x$-slice of the selecting operator. At $f_i$ put the current row of $f_i Y_x$ in its $f_i x$-slice, filling all other slices arbitrarily. Injectivity at each input type makes the prescriptions compatible. These rows exhaust the description of the operator at $r$, and its value at each $x$ is $Y_x$ as an entire entity. For Gallin Extensional Comprehension, pull any actual row back at each $f_i$ along $j$, using the identity at $r$. Since $je_i=j$, the resulting relation and its complement are persistent.

At input type $\sigma$ give a tester full current row and row $f_i[D_\sigma(r)]$ at $f_i$. It necessarily accepts every actual input. A missing individual is $1$ at $s$. For any relational sort a target entity with full $1_s$-row and empty $e_i$-row cannot be in $f_i$'s image: since $e_i f_i=f_i$, those two rows of every image coincide. Thus $\forall x\,\Box Xx$ and $\neg\Box\forall x\,Xx$ at $r$.

## The ordinal benchmark and the Boolean intervals

Write $\rho=(eet)(et)t$ for the ordinal-predicate type. Consider the set $Z$ of all $r$-entities at this type whose identity row depends only on the current extensions of the supplied relation and field and whose rows at **all** $f_i$ use one common Boolean table on their current extensions at $s$. The individual domains have respectively one and two elements. There are finitely many possible current relation/field tables on either domain, hence $Z$ is finite as a set of *whole entities*. It is the current extension of an admitted predicate.

Ordinal zero, which tests well-ordering, belongs to $Z$. All current subfields are present and the test uses only the current order and field extensions. Ordinal successor forms the initial segment below a current member and tests the previous ordinal there. Its field and relation are determined extensionally at each point, so it preserves $Z$. Suppose that $Y$ is rigid and that its current members belong to $Z$. Its current members then form a finite list. Equality to the disjunction of their haecceities follows from weak persistence and weak inextensibility: each member's haecceity lies below $Y$, while their finite union necessarily accepts each current member. At each $f_i$ the current instances of $f_iY$ are consequently exactly the transported members of this same list. The ordinal limit tests well-ordering and the conjunction of the listed ordinal applications. The list thus determines a current extensional table at $r$ and a single common extensional table at all $f_i$. Repetitions after transport do not affect conjunction. Therefore the limit belongs to $Z$. Instantiating the impredicative ordinal test with the predicate having actual row $Z$ now bounds the actual ordinal carrier by this finite set. This specializes the map's one-individual threshold argument to the present two individual domains. [Ordinal benchmark and smallness](../index.html#principle/forcing-possibilism)

At the root every external subset and every graph between current types is admitted as a current extension. An infinite carrier therefore contains a countably infinite subset $D$, strictly larger than the finite benchmark. Every subset $A$ of size strictly smaller than $D$ is finite. A finite subset of $D$ of size $2^{|A|}$ codes all subsets of $A$ by an admitted relation, giving the required power-closed witness. Thus every revised-small algebra is finite. Conversely, a finite Boolean algebra with $k$ atoms is isomorphic to the powerset of $k$ points. The root proposition algebra is the full powerset of $\{1_r,f_0,f_1,\ldots\}$ ordered by inclusion. A proposition consisting of $k$ arrows has exactly that powerset as its principal ideal; the case $k=0$ uses the empty proposition. Full current graphs supply the requested order isomorphism at every carrier type.

# Functional Choice and strong atoms without the Barcan Formula

At the designated point Functional Choice holds and the Barcan Formula fails at every input type. Necessarily every atom is a strong atom, at every relational type, and necessarily there is a true strong atom. The construction uses ZFC.

## Current, entrance and return rows

Let $E_e^r=\{0\}$ and $E_e^s=\{0,1\}$. Let $j$ collapse the latter set to the former, and let each $h_i$, for $i\in\mathbb N$, send $0$ to $0$. For a relational type $\tau=\alpha_1\ldots\alpha_d t$, write $A^b=\prod_k E_{\alpha_k}^b$, also allowing the empty tuple. Inductively set
$$
 E_\tau^r=\mathcal P(A^r)\times
  \big(\mathcal P(A^s)^{\mathbb N}/{=^*}\big),
 \qquad E_\tau^s=\mathcal P(A^s)\times E_\tau^r.
$$
Two sequences agree modulo $=^*$ when their entire rows coincide at all but finitely many indices. The first coordinate gives the current extension. Write $j(S,x)=x$. For each $x=(R,[U])$ at $r$ choose one representative sequence $U^x$ and put
$$
 h_i x=(U^x_i,x).
$$
Thus $jh_i x=x$ at every type. Each individual $h_i$ uses chosen representatives. Only the aggregate along a free ultrafilter defines an arrow. The reduced sequence factor replaces the individually observable entrance rows of the [full retraction](full-two-object-retract.html).

## The action model

At the initial stage the base kind is $r$ and the index ultrafilter is principal on a singleton. The typed domains at a stage of kind $b$ with index ultrafilter $D$ on $I$ are the ultrapowers $(E_\tau^b)^I/D$. Interpret current application pointwise modulo $D$. A stage of kind $r$ has, for every family of free ultrafilters $U_l$ on $\mathbb N$ indexed by $l\in I$, a successor of kind $s$. Its indices are $(l,i)\in I\times\mathbb N$, and a set is large if its fiber at $l$ belongs to $U_l$ for $D$-almost every $l$. The arrow sends $[x_l]$ to $[h_i x_l]_{(l,i)}$. At $s$ a single step to kind $r$ retains $I,D$ and sends $[z_l]$ to $[jz_l]$. Take finite histories as objects and finite paths as arrows, with identities and concatenation. This is a set. All the maps on classes are well-defined. Changing the chosen representatives changes each $i\mapsto h_i x_l$ at only finitely many indices, so it has no effect on any entrance map.

Distinct relational entities have different extensions at some continuation. At an $r$-stage, on a $D$-large set of indices either the current rows differ, or the entrance sequences of rows differ on infinitely many indices. In the first case choose a distinguishing argument tuple at each good index. In the second choose $U_l$ containing the infinite set of disagreements at each good $l$, and choose a distinguishing tuple at the successor. An ultrafilter makes one orientation of the disagreement large, so the family of tuples separates the two extensions there. At an $s$-stage a difference is in either the current rows or the return coordinates on a large set of indices. In the latter case take the deterministic return and apply the $r$ argument. Equal entities remain coextensive by well-definedness. This proves the required intensional identity criterion, including for propositions.

Here are the details of term closure. Evaluate a variable by its value; local truth uses current application, entity equality, ordinary Boolean operations and quantifiers over the current base carrier. For $L=\lambda\bar y.\phi(\bar y,\bar a)$ on $r$-parameters, set its current row to $\{\bar y:\phi_r(\bar y,\bar a)\}$ and its $i$th entrance row to
$$
 \{\bar z:\phi_s(\bar z,h_i\bar a)\}.
$$
On $s$-parameters $\bar b$, give $L$ its local $s$-row and give it as return coordinate the $r$-value of this abstract on $j\bar b$. At each term form the $r$-case first. It requires just the current evaluations of proper subterms; hence the $s$-case can use that $r$-case without circularity. A compound proposition uses the same construction with the empty tuple, performing its local connective, equality, application or quantifier. Partial application reads the relevant rows on the transported supplied arguments, leaving the remaining argument places free.

The $j$-coordinate of each term at $s$ is its $r$-denotation on the returned parameters. At $r$, the current row of $h_i L$ and the current row of the abstract on $h_i\bar a$ coincide for cofinitely many $i$ as entire rows, uniformly in the newly bound arguments. The return coordinates coincide because $jh_i\bar a=\bar a$. For partial application the same calculation uses a finite intersection of the cofinite sets for the operator and supplied arguments. Thus denotations commute with the deterministic return and with every genuine ultrafilter entrance. Interpret a term at each iterated stage by the family of its base denotations. The ordinary Łoś induction gives the current truth computation for every formula; existential witnesses at the good indices form an admitted ultrapower element. The transport computation makes each abstract's extensions at all continuations those required by the action semantics. Together with extensional separation this yields a C model. In particular the defined ordinary box agrees with truth at all continuations. Compare the [varying-ultrafilter separation argument](iterated-ultrafilter-fronts.html).

## Functional Choice

Given a serial current relation at the initial $r$-stage, choose an allowed $Y_a\in E_\tau^r$ for each input $a\in E_\sigma^r$, where $\tau=\beta_1\ldots\beta_d t$. To define the selecting operation $X$ at type $\sigma\beta_1\ldots\beta_d t$, give $X$ the root row prescribed on $(a,\bar z)$ by the current row of $Y_a$ at $\bar z$. Prescribe its $i$th entrance row at $(h_i a,\bar w)$ by the current row of $h_iY_a$ at $\bar w$, and give value false on other inputs. Each $h_i$ is injective by $jh_i=1$, so this determines a row. Every sequence of such rows is admitted. For each fixed $a$ the current and entrance data of $X(a)$ agree with those of $Y_a$ up to eventual equality of entire rows. Thus $X(a)=Y_a$ as an entity, giving Functional Choice at every admitted output type.

## Strong atoms

The Boolean orders of relational entities at the two base kinds are the coordinate orders in the displayed products, with eventual inclusion in the sequence component. This follows from componentwise Boolean operations, or from the separation calculation. The sequence algebra has no atoms. For any nonzero sequence, partition the infinite set of its nonempty rows into two infinite parts and restrict the sequence to each. Consequently an $r$-atom has the form $(\{\bar b\},[\varnothing])$. At an entrance it is represented almost everywhere by an $s$-atom with empty current row and that singleton as its return coordinate. A return sends it back to the $r$-atom. The other $s$-atoms are singletons in the current $s$-row with bottom return component. These go to bottom on a return and remain there.

At every stage an atom is represented by base atoms almost everywhere by Łoś. The preceding calculations show that it transports through any finite path to a family consisting almost everywhere of atoms or bottom. Each decides every tester available there, which gives strong atomhood. This proves the boxed atom principle. Both base kinds have a true current singleton at $t$, also giving necessary Strong Actuality. The root proposition algebra is $\mathbf 2\times(\mathcal P(\mathbb N)/\mathrm{Fin})$ and has one atom.

## Failure of Barcan at every type

At input type $\sigma$, let the tester have full current $r$-row and let its $i$th entrance row be $h_i[E_\sigma^r]$. It holds necessarily of each current input. At an entrance the input is in the indicated image, up to representative changes at finitely many indices; at a return it recovers the original input by $jh_i=1$. The same calculation applies at every subsequent stage. But the first entrance has a family of inputs outside those images. At $e$ take the new individual $1$ at every index. At a relational type fix $a\in E_\sigma^r$ and give $z_i\in E_\sigma^s$ return coordinate $a$ but a current row different from that of $h_i a$. The common left inverse implies $z_i$ is outside the entire image of $h_i$. The input $[z_i]$ fails the tester. This gives $\forall x\,\Box Xx$ and $\neg\Box\forall x\,Xx$.

## Finite weakly rigid bounds at the root

Suppose a weakly rigid $F$ at $r$ has infinitely many current tuples. Choose distinct tuples $x_n$ from its extension. By weak persistence, the set of $i$ such that $h_i x_n$ lies in $F$'s $i$th entrance row must be cofinite for each fixed $n$: any infinite complement would be contained in a free ultrafilter at the first entrance. Denote these cofinite sets by $A_n$. For $i\in A_0$, take the largest $k(i)\le i$ with $i\in\bigcap_{n\le k(i)}A_n$. This index tends to infinity modulo the cofinite filter. On these $i$ give a tester full entrance row except for the single tuple $h_i x_{k(i)}$; give it full rows at the other indices and at the root. For a fixed current tuple $x$, injectivity of $h_i$ implies that any exclusion of $h_i x$ requires $x=x_{k(i)}$. This can happen at only finitely many indices, so the tester necessarily holds of each current tuple through any number of rounds. At the first free-ultrafilter entrance the family $h_i x_{k(i)}$ (filled arbitrarily off $A_0$) is in $F$ and fails the tester. This contradicts weak inextensibility.

Every root weakly rigid bound therefore has a finite current extension. It equals the corresponding finite union of tuple haecceities by weak persistence and weak inextensibility. In particular it is rigid. The finite-bound theorem gives rigidity of both canonical power predicates for such bounds, proving Tame Rigidity, Weakly Rigid Power and Rigid Power at the designated root. ## Weak rigidity at a return and both necessary powers

At the base kind $s$, the relation $G=(S,H)$ is weakly rigid exactly when $H$ is rigid at $r$ with finite current row $j[S]$. To see necessity, weak persistence includes $j[S]$ in the current row of $H$, and weak inextensibility gives the reverse inclusion by the return tester in the next section. For any $r$-tester $T$ necessarily holding on each $j[S]$-member, lift it to the tester $(\top,T)$ at $s$. This necessarily holds on $S$, so $H\le T$. Weak persistence of $H$ follows by taking for each of its current members a preimage in $S$ and applying weak persistence of $G$. The finite-bounds argument at $r$ now makes $H$ a finite union of the haecceities of exactly $j[S]$. Conversely, given rigid $H$ with this current row, each member of $S$ persists at and beyond the return by persistence of $H$. A tester holding necessarily on each member of $S$ has return coordinate necessarily holding on each member of $j[S]$, and that coordinate bounds $H$ by weak inextensibility. The current inclusion also holds. Thus $G$ is weakly rigid and is fully rigid since every proper continuation goes through its rigid return. This proves Tame Rigidity at both base kinds and, by Łoś, necessarily.

For either canonical power of $G$, consider any weakly rigid subrelation $Z$ below a later image of $G$ along a proper path $fj$. There $fH$ is a finite union of haecceities. The current members of $Z$ form a subset of the finite tuple images from $j[S]$; weak rigidity identifies $Z$ itself with their haecceity union. Choose $D\subseteq j[S]$ with precisely these images, and put $S'=S\cap j^{-1}[D]$. Then the relation $(S',\bigvee_{d\in D}H_d)$ is rigid at $s$ by the characterization just proved. It lies below $G$ and transports to $Z$. At the identity take $Z$ itself. Thus any tester necessarily accepting each current power member accepts each future member of the corresponding power. The power property is also weakly persistent because weak rigidity and rigidity coincide throughout the cone and inclusion persists. Tame Rigidity upgrades this to rigidity. Both powers hold at each base kind and hence necessarily.

## Inextensible comprehension

At the initial stage a set of tuples admits an inextensible coextension exactly when it is finite. Finite unions of tuple haecceities are rigid. For the converse, write $F=(R,[U_i])$ and suppose $F$ is inextensible, so it is weakly inextensible throughout the cone.

At base kind $s$, weak inextensibility of $G=(S,(R,[U]))$ implies $R\subseteq j[S]$. Indeed, take a tester that is full currently, has current return row $j[S]$, and has full entrance rows in that return coordinate. It necessarily accepts every tuple $b\in S$: all odd returns from $s$ test $jb\in j[S]$, and all other rows are full. Hence every tuple in the return row $R$ satisfies the tester. Applying Łoś to weak inextensibility at each possible first free-ultrafilter stage shows that $h_iF$ satisfies this base assertion for cofinitely many $i$. Thus $R\subseteq j[U_i]$ for all such $i$, simultaneously for the entire row $R$.

If $R$ is infinite, choose distinct $x_i\in R$ and, at every good $i$, some $b_i\in U_i$ with $jb_i=x_i$. Make a tester full at the root and throughout its entrance rows except for the single exclusion $b_i$ at each good $i$. For each fixed old tuple $x$, the equation $h_ix=b_i$ implies $x=x_i$, which occurs at most once. Every old tuple thus necessarily passes the tester through arbitrarily many rounds. At the first free-ultrafilter entrance the tuple represented by the $b_i$ belongs to $F$ and fails the tester, a contradiction. The universal property on the infinite proposition sort consequently has no inextensible coextension.

Weakly Inextensible Comprehension holds necessarily. At $r$ the coextension $(R,[\varnothing])$ works for every actual row $R$. Any tester necessarily accepting every member of $R$ already contains $R$ in its current row. At each even continuation its transported current row contains the entire iterated ultrapower of $R$; at odd steps the coextension has empty row. At $s$ an arbitrary current row with bottom return coordinate has no members at any nonidentity continuation. These base computations transfer by Łoś.

## Infinity, arithmetic and analysis

At each base kind all subsets of each current carrier occur as current predicate extensions. In particular the extension consisting of the standard Frege numerals at a given type is available as an inductive test. The least inductive property therefore consists precisely of the standard numeral denotations there. At $t$ the carrier is infinite at each kind, and arbitrary current rows realize all standard finite sizes. Thus the Peano guard and the Axiom of Infinity at $t$ hold necessarily by Łoś. The root number property at this type has infinitely many members and fails weak rigidity by the finite-bounds result. This refutes Arithmetic Necessitism.

The root proposition sort has continuum many entities. At this sort choose a countable number domain, codes for all its subsets, and the usual successor and membership relations; all required current extensions are admitted. Every actual real number structure has an infinite number row, since its standard successor iterates are distinct. The number row therefore cannot be weakly rigid. Both Analytic Necessitism and Second-Order Analytic Necessitism fail already at $t$.

The sentence-level Necessity of Arithmetic and Necessity of Second-Order Analysis hold. In either base kind, wherever the Peano guard holds, the preceding inductive test makes the successive standard numerals exactly the distinct numbers, giving standard arithmetic. Wherever a real number structure exists, the full current predicates force its numbers to be a copy of the standard naturals and its reals to represent exactly their full powerset. Full current rows at every arity also represent all external relations on those domains. Thus each guarded arithmetic or analytical sentence has the same truth value at both kinds wherever instantiated; each such fixed sentence passes to all the iterated stages by Łoś.

## Countable completeness, well-ordering and the signature

Let $\mathbb N$ be partitioned into disjoint infinite sets $B_n$. In the root proposition algebra take $p_n=(0,[B_n])$. Given any upper bound $(b,[J])$, each $J\cap B_n$ is cofinite in $B_n$. Delete from $J$ one element of each $J\cap B_n$. The result is strictly smaller modulo finite differences and still bounds every $B_n$. The $p_n$ therefore have no join. A current predicate picks out this family and an admitted current graph sends $p_n$ to the distinct $n$th Frege numeral counted at $t$. This refutes Countable Boolean Completeness and Boolean Completeness already at $t$. The same atomless quotient contains nonzero propositions with no atom below them, refuting Atomicity at $t$.

For each sort choose a set-theoretic well-order on each of its two base carriers. The relation with that current $r$-order and constant entrance row the $s$-order is a necessary well-order. At every subsequent stage the internal well-order sentence follows by Łoś from the base assertions.

Use one propositional name $c$. Countably many closed pure propositional terms denote only countably many entities, whereas $\mathbf2\times(\mathcal P(\mathbb N)/\mathrm{Fin})$ has size continuum. Interpret $c$ outside their denotations, and transport its value along the unique history to each stage. This gives Independence for this single-name signature.

## Self-atoms, two-hat necessity and Mathematical Possibilism

Every self-atom is a strong atom at every relational type throughout the model. At $r$, any nonzero entrance component of $F$ gives a first free-ultrafilter successor where $F$ is instantiated and both its current and return components are nonzero. It is not an atom there. A self-atom at $r$ therefore has empty entrance component and must be a singleton in the current row. At $s$ a self-atom with nonempty current row must already be an atom. A self-atom with empty current row must have a nonzero return coordinate; that coordinate is a self-atom at $r$ and therefore an atom. In this case it too is an $s$-atom. The hereditary strong-atom calculation now applies.

Every truth is two-hat necessary at every stage. At $r$ let $a$ be the true current-only propositional atom. It holds exactly at the even continuations, where every true root proposition still holds by the diagonal returns. At each odd continuation of kind $s$, there is a new true current-only proposition $v$ whose return coordinate is bottom. Once the deterministic return occurs, $v$ becomes impossible. No future $a$-point can therefore see a $v$-point from there. At the odd continuation $v$ witnesses $\neg\Diamond_{\ne}a$, by the dual definition $\Diamond_{\ne}a=\forall v\,(v\to\Diamond(a\land\Diamond v))$. Thus $a$ witnesses two-hat necessity of every root truth. At $s$ use its own $v$ as the witness: $v$ is impossible at every proper continuation. Applying Łoś proves the assertion at all stages.

Mathematical Possibilism fails. On four current propositions use a current predicate and order coding the four-element Boolean algebra. It is small: no nonempty finite $k$-element set is power-closed, because a subset of size $k-1$ has $2^{k-1}\ge k$ subsets, all available as current rows. The empty set cannot be larger than the ordinal benchmark. The root proposition algebra has only one atom, so no principal ideal can be a four-element Boolean algebra.

Throughout, the individual sort at each stage has exactly one or two members, since finite fixed carriers retain their sizes in ultrapowers. The third standard finite count is never instantiated. Both Potential Infinity and Possible Infinity at $e$ fail.

# Negative Affine Anti-Invariance ⇒ Reflection Anti-Invariance

<p class='cert'>Result — Source: Symmetries of Value, Lean `UnboundedUtility.Proofs.negative_affine_implies_reflection`; produced by Zachary Goodsell (cited paper); recorded by GPT-6 (Codex), 2026-09-08; transcription and random-variable formulation.</p>

## Premises

- **Negative Affine Anti-Invariance.** For all real $a>0$ and $b, X \succeq Y$ iff $- aY+b \succeq - aX+b$.

## Conclusion

- **Reflection Anti-Invariance.** $X \succeq Y$ iff $- Y \succeq - X$, using the one fixed normalized origin 0.

## Proof

Set $a=1,b=0$. The order is reversed.

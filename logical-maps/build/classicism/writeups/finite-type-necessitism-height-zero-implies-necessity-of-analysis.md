# Finite-Type Necessitism: height 0 ⇒ Necessity of Analysis

<p class='cert'>Result — Source: Kodsi, Finite-Type Necessitism (2026); produced by Daniel Kodsi, with assistance from GPT-6 Astra (OpenAI); recorded by ChatGPT, at Daniel Kodsi’s request.</p>

## Premises

- **Finite-Type Necessitism: height 0.** The exact height-0 fragment of Finite-Type Necessitism, at every carrier type. A possible Peano presentation has a rigid realization at the same type, with its full rigid represented power.

## Conclusion

- **Necessity of Analysis.** Every first-order analytical sentence is either true in every real number structure in every possible world or false in every real number structure in every possible world. One sentence for each type $\sigma$ and each first-order analytical sentence.

## Proof

A possible real structure supplies a Peano presentation. F0 gives its rigid full first power; Dedekind cuts yield a rigid necessarily real reference at the native predicate type. Cross-type categoricity transfers first-order analytical truth to all possible real presentations. [Paper (PDF)](https://github.com/dkodsi/Logical-Maps/blob/classicism-next-batch-2026-10-30/logical-maps/topics/classicism/papers/finite-type-necessitism.pdf); [source](https://github.com/dkodsi/Logical-Maps/blob/classicism-next-batch-2026-10-30/logical-maps/topics/classicism/papers/finite-type-necessitism.tex).

## Notes

The reference may live at another type; this conclusion is Necessity of Analysis, not same-carrier Analytic Necessitism.

## 1. The progressive cover

Use the set-sized pure-C-complete old family, sufficient typed name supply,
full finite-pin/old-landing domains, named constants and unchanged old
components described in [named-permutation construction](https://github.com/dkodsi/Logical-Maps/blob/classicism-next-batch-2026-10-30/logical-maps/topics/classicism/writeups/interpretation-cover-named-permutations.md), §1.
Work in external ZFC with that same inherited action-model existence
input. Each typed name set is indexed by an infinite initial ordinal
\(\lambda\), so there is a larger index above each index.

Replace the root permutation group by the monoid of **all** typed maps
\(f\) such that \(f_\sigma(\alpha)\geq\alpha\). They may identify
names and need not preserve order between distinct inputs. Identity and
composition are progressive. Retain every typed interpretation into every
old object; \(If\) and \(kI\) are still permitted. There is no old-to-root
arrow and the designated root symmetry group is trivial.

If \(S\) pins an entity, \(fS\) pins its root transport. Two arrows
agreeing on \(S\) give equal entire transported entities, since every
further composite still agrees on \(S\). The union of parameter pins
therefore makes the entire target environment equal before any term or
quantifier is evaluated. Bound variables range over the full target
domain; no preimage assumption is needed. Old sections are old admitted
term denotations. This proves all-type closure, landing and the usual C
soundness, with the same theoremhood restriction as the source construction.
Arbitrary constant root tables with zero old rows are admitted and separate
distinct whole entities by current singleton predicates.

The signature constants use distinct designated names and relational named
lifts with zero root rows. Their whole transport at \(I\) is \(I(c)\).
For any consistent closed \(\Sigma\)-sentence, existentialize its finitely
many constants to obtain a pure consistent sentence. A component realizes
it, and an unrestricted interpretation assigns its witnesses to those
coordinates. Thus the original sentence is possible. This proves native
signature Maximalism, hence pure Maximalism, without changing the reference
theory to one containing any optional root principle.

## 2. Current Truths are ND-necessary

For a finite typed name set \(S\), let \(q_S\) be true at exactly the
root maps fixing \(S\) pointwise, with all old rows false. It is pinned
by \(S\) and lands as bottom. If a continuation \(g\) makes
\(gf\) fix a name of index \(\alpha\), then

\[
\alpha\leq f(\alpha)\leq g(f(\alpha))=\alpha.
\]

Thus \(f\) already fixed that name. Conversely identity continues any
map fixing \(S\) to a fixing map. Old continuations never return to the
root and see only bottom. Therefore, as **whole propositions**,
\(\Diamond q_S=q_S\).

If a current truth \(p\) has pin \(S\), every root map fixing \(S\)
agrees with identity on its pin, so \(q_S\leq p\). The currently true
\(q_S\) therefore witnesses

\[
\Box_{\ne}p:=\exists q\,[q\land\Box(\Diamond q\to p)].
\]

This proves the current principle \(\forall p(p\to\Box_{\ne}p)\),
whose existing ID is `distinctness-preserving-collapse`. It is not
Necessary Distinctness. The native operator inequalities give the weaker
current modal consequences; nothing boxes this root verdict.

## 3. Atomlessness

Let a nonzero proposition \(p\) have finite pin \(S\). If it is true
at a root map \(f\), choose an individual name \(a\notin S\). Change
only \(f(a)\) to a strictly larger index to obtain another progressive
map \(f'\). They agree on \(S\), so \(p\) is true at both. The
admitted proposition with root row \([h(a)=f(a)]\) and zero old rows
distinguishes them. Its intersection with \(p\) is nonzero and proper.

If \(p\) is witnessed in an old target, choose a fresh propositional
name outside its pin. Interpret it once as top and once as bottom in
the same target, leaving all pinned values fixed. Its whole named lift
separates the resulting interpretations while \(p\) remains true.
Both parts of \(p\) are again nonzero. These two cases prove native
Atomlessness over the entire admitted propositional domain.

## 4. Failure of weakly inextensible comprehension at tt

Choose distinct individual names \(c_n\) and write
\(p_n=q_{\{c_n\}}\). These are distinct nonbottom whole propositions.
Their transport at a root map \(h\) is \(p_n\) if \(h\) fixes
\(c_n\), and bottom otherwise. Every old transport is bottom.

The profile \(E\) whose extension is \(\{p_n:n\in\mathbb N\}\)
at **every** root loop and empty at every old target is admitted at
type \(tt\), with empty pin and bottom landing. Suppose a current
coextension \(Y\) were weakly inextensible, and let \(S\) pin \(Y\).
Choose \(c_k\notin S\) and a progressive \(h\) fixing \(S\) but
moving \(c_k\). Its \(Y\)-row still contains the whole proposition
\(p_k\), since that row equals the identity row on all root arguments.

Define the tester \(T^{tt}\) by its complete rows. At a root map \(g\)
it contains every proposition when \(g\) fixes \(c_k\), and every
proposition except \(p_k\) otherwise. At an old target it contains
exactly bottom. It is \(\{c_k\}\)-pinned, and each whole old section
is the existing closed operation \(\lambda q(q=\bot)\); hence it lands.

Every current \(p_n\) necessarily satisfies \(T\). At a loop moving
\(c_k\), the transport of \(p_k\) is bottom, whereas for \(n\ne k\)
the transport is either \(p_n\) or bottom; neither is the omitted
\(p_k\). At a loop fixing \(c_k\) the tester is universal. At every
old target all transported \(p_n\) are bottom. Thus every current
\(Y\)-member necessarily satisfies the tester.

Weak inextensibility would give \(Y\leq T\). But at \(h\), the
future \(Y\)-row contains \(p_k\) and the \(T\)-row omits it.
This uses the full future-domain argument \(p_k\), not just images of
current arguments. The contradiction proves failure of the \(tt\)
instance, hence of the native full schema. It concerns weakly inextensible
comprehension, not Intensional Choice; its type-\(t\) instance is not
being claimed to fail.

The existing Vicinity/collapse-to-Actuality result and Atomlessness already
derive failure of Vicinity. The BF, choice and individual-parameter possibility verdicts for these progressive
loops are established directly below. No boxed-collapse, Boolean Completeness
or Strong Possibility claim is made.


## 6. The precise current-fullness lemma

For every finite tuple of admitted types and every external subset R of the product of their WHOLE current domains, define a profile with row R at every root loop and empty rows at every old interpretation. This has empty typed pin; every whole old section is the appropriate bottom relation. Root designated symmetry is trivial. Thus it is admitted at the required relation type. The root input domains are the same at all root loops, so these rows are well typed even when R names specific intensional entities. No transport invariance of R is an additional admission requirement.

The lemma asserts arbitrary current relation extensions. It does **not** assert arbitrary operations whose outputs are whole relational entities. In particular, a selected graph is not automatically an admitted Functional Choice operation. Only the relation lemma is used here.

## 7. Choice and transversal scopes

For native Relational Choice, a currently serial U of type sigma-tau-t has an externally selected output for each current sigma-entity, by metatheoretic ZFC Choice. Represent its graph using §6. The native requirements of functionality and inclusion in U are entirely current, so this is an admitted witness. Both input and selected-output type may be e: the witness still ends in t. No forbidden e-valued function type is introduced. The same argument works directly on finite tuples.

For native Transversal Choice, independently choose one member of each actual equivalence class of the current extension of R on D_sigma. Represent that selected subset using §6. The native equivalence and transversal clauses are unboxed, so this proves the required schema, including sigma=e. It does not use or establish a general RC-to-TC implication in C.

For Transversal itself there is also a direct check. For each A subset of D_sigma, let C_A be the canonical profile having row A at every root loop and empty old rows. Represent the set of these whole C_A objects by a current predicate. Every current property has exactly one C_A with its current extension; two canonical profiles with the same A are identical whole entities. Thus the native uniqueness is identity, not merely coextension. This also proves Transversal directly.

## 8. Quantified infinity really follows

The individual domain is an infinite name set with literal current equality. External infinitude alone would not suffice for the native impredicative axiom; the required higher-type witness is as follows.

Let Z_n be the whole current denotation of the closed n-fold successor of the Frege zero at e. By §6 the predicate W with current extension exactly {Z_n : n is a standard natural number} is admitted at type `((et)t)t`. It contains zero and is closed under the current successor operation. Consequently the exact universal-W definition of FiniteCardinality_e forces each current finite cardinality Z to equal a Z_n as a whole entity.

An ordinary external finite induction using the displayed definitions in `background/arithmetic.md` shows that Z_n currently holds of X exactly when the current extension of X has n individuals. The successor step removes one member using literal individual equality. Thus no Z_n holds of the universal infinite individual property. This proves `axiom-of-infinity-e`, with the finite Infinity Schema following by its recorded implication. No standardness assumption about arbitrary Henkin old domains is used.

## 9. Exact Possibility+ restrictions

The old complete component family and ALL typed interpretation arrows are unchanged. A consistent formula with only finitely many displayed individual free variables has an old witness after existential closure. For a signature formula, first replace its finitely many occurring constants with distinct typed variables and existentially close them too; the constant-elimination consistency argument applies.

Given pairwise distinct current individual names a_i, map them to the witnessed old individual values. For the signature version, also map the designated names of the constants occurring in P to their witnessed old whole values. The native side condition requires each a_i to differ from the denotation of every INDIVIDUAL constant OCCURRING IN P. This makes the assignments compatible. It does not require avoidance of unused signature constants. Distinct symbols have distinct designated names, and types have disjoint name sets; the old values themselves may coincide. Arbitrary interpretations permit the finite assignment to extend to a total one.

Whole old transport of relational named lifts gives the assigned old entities. Formula satisfaction then gives the required diamond. Empty tuples are included. The restriction to individual free variables is essential; no claim is made about arbitrary free relational parameters. No progressive restriction applies to these old interpretation arrows. This is the interpretation-cover transfer mechanism.

## 10. BF_t fails by a full-domain tester

Write c for the least individual name, indexed 0, and q_c for the admitted root proposition with truth row [g(c)=c] and false old rows. Put X_g=D_t if g(c)=c and X_g=D_t minus {q_c} otherwise, with whole universal old sections. This is a `{c}`-pinned admitted tt-profile.

If g(c)>c, progressiveness implies c is absent from the image of g_e. For every current p with finite typed pin P, transport rho_g p has pin g[P], whose individual part omits c. Conversely q_c cannot have any finite pin omitting c: identity and the progressive map changing only c to its successor agree on such a pin but disagree on q_c. This remains true if the pin contains the successor name, since these maps are not required to be injective or monotone between different inputs. Hence rho_g p is never q_c.

At loops fixing c, X is universal; at loops moving c, it contains every transported current p by the preceding argument; at all old arrows and their futures it is universal. Thus the antecedent `forall p. Box Xp` of the native BF_t formula holds. At a loop moving c, the FULL target domain still contains q_c, and X_g excludes it. Hence `Box(forall p. Xp)` fails.

This is a direct instance of the actual native formula. The fixed row value q_c is permitted in a raw admitted profile; it is not being smuggled in as an untransported parameter of a lambda term. The proof does not confuse a finite pin, or a transport image, with the full future quantifier domain. Ordinary relational/all-type BF fail as their recorded BF_t consequences. No BF proof from an earlier all-map or permutation cover may be inherited.

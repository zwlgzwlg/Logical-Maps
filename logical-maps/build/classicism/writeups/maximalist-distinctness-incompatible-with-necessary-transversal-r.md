# Maximalism (pure) ∧ □Transversal ⇒ ⊥

<p class='cert'>Result — Source: Misc.; produced by Claude Opus 5.5 (Anthropic), 8 October 2026, at Cian Dorr's suggestion; recorded by Claude Opus 5.5 (Anthropic), 8 October 2026.</p>

## Premises

- **Maximalism (pure).** Every closed pure identity not provable in C is false. The non-theorem condition is metalinguistic.
- **□Transversal.** Necessarily, there is a property of properties that picks out exactly one property from each coextension class, that is, exactly one property coextensive with any given property.

## Conclusion

- **⊥.** These premises cannot all hold together.

## Proof

Transversal fails in symmetric-infinite-classes, a model of C, so some closed pure instance of it is not a theorem of C and its negation is consistent with C. The possibility form of Maximalism (pure) makes that negation possible, and the boxed principle makes the instance necessary.

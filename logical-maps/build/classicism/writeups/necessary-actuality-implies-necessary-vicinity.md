# □Actuality ⇒ □Vicinity

## Premises

- **□Actuality.** Necessarily, there is a true proposition that entails every true proposition.

## Conclusion

- **□Vicinity.** Necessarily, there is a true proposition that entails the possibility of each true proposition.

## Proof

The argument of the unboxed result derives Vicinity from Actuality in C, with no optional hypothesis, so Actuality → Vicinity is a theorem of C. Necessitate it and apply K to $\Box$Actuality.

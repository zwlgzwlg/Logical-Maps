## Package

- **Necessary arithmetic infinity.** Necessarily, the canonical successor at type rho never takes a number to zero and is injective on the canonical numbers. One instance for each finite source type rho.
- **¬ Arithmetic Necessitism.** Given that necessarily zero is not a successor and successor is injective on numbers, the numbers at $\sigma$ form a rigid property with necessarily distinct instances. One sentence for each type $\sigma$.

## Definition

Finitary Henkin component K satisfies every Box I*_rho and has an additional canonical t-number c not equal to any standard numeral, plus Q necessary of every standard numeral but false of c. Attach a full present using pairs (current relation, K-entity), retaining K quantifiers over their whole domains. The root has all Box I*_rho, but the whole numerical predicate at t is not weakly inextensible.

## Arguments

### Holds Necessary arithmetic infinity. Fails Arithmetic Necessitism.

The same root satisfies every boxed canonical I* schema, with the active guard at t, but its whole N_t has a new K-component member excluded by an admitted persistent test. Thus it is not rigid, refuting Arithmetic Necessitism. Total predecessor operations follow from the bare-C boxed guard theorem.

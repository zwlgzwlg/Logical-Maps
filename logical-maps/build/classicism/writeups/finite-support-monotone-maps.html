Finite-support action model: monotone maps of N

Model — Source: Classicism (2024); produced by Andrew Bacon and Cian Dorr; recorded by OpenAI Codex (GPT-6), prompted by Zachary Goodsell, 17 September 2026.

Package

  • Atomlessness. Atomlessness in the displayed closed propositional formulation.
  • Truths are two-hat necessary. Every truth is two-hat necessary.
  • Rigid Power. If a relation is rigid, so is the property of being a rigid relation that entails it.
  • Tame Rigidity. Every weakly rigid relation, including a proposition, is rigid.
  • Axiom of Infinity (type e). There are not finitely many individuals. No finite cardinality holds of the universal property, so the domain of the type cannot be exhausted by finitely many steps from the empty property.
  • Axiom of Infinity (type t). There are not finitely many propositions. No finite cardinality holds of the universal property, so the domain of the type cannot be exhausted by finitely many steps from the empty property.
  • Arithmetic Necessitism. Given that necessarily zero is not a successor and successor is injective on numbers, the numbers at \sigma form a rigid property with necessarily distinct instances. One sentence for each type \sigma.
  • Infinity Schema (type e). There are arbitrarily many pairwise distinct entities of this fixed type; one sentence for each positive integer n.
  • Infinity Schema (type t). There are arbitrarily many pairwise distinct entities of this fixed type; one sentence for each positive integer n.
  • □Intensional Choice. Necessarily, if a property is necessarily instantiated, then some property entailing it is necessarily uniquely instantiated.
  • □Relational Choice. Necessarily, every serial binary relation has a functional subrelation.
  • □Transversal Choice. Necessarily, every equivalence relation, at any type including e, has a transversal, that is, a property with exactly one instance in each of its cells.
  • □Self-atoms are atoms. Necessarily, at each relational type, every self-atom is an atom.
  • □Self-atoms are strong atoms. Necessarily, at each relational type, every self-atom is a strong atom: it necessarily entails every entity of the type or its negation.
  • □Atomlessness. Necessarily, every possible proposition has a possible proposition strictly below it.
  • □Atoms are self-atoms. Necessarily, at each relational type, every atom is a self-atom: necessarily, if it is instantiated, it is an atom.
  • □Atoms are strong atoms. Necessarily, at each relational type, every atom is a strong atom: it necessarily entails every entity of the type or its negation.
  • No Pure Contingency. Each closed sentence of the pure language, if true, is necessary. This is a sentence schema, not a quantifier over propositions.
  • Necessity of Second-Order Analysis. Every second-order analytical sentence is either true in every real number structure in every possible world or false in every real number structure in every possible world. One sentence for each type \sigma and each second-order analytical sentence.
  • Transversal Choice. Every equivalence relation, at any type including e, has a transversal, that is, a property with exactly one instance in each of its cells.
  • ¬ Witnessed Possibility. For pure-formulas P with free variables among a finite tuple x, and distinct matching nonlogical constants c, a witness to P entails that P at those constants is possible.
  • ¬ No Contingency (signature Σ). Each closed sentence of the language of the fixed signature Sigma, if true, is necessary. A sentence schema, standing to No Pure Contingency as Possibility Maximalism (signature Σ) stands to Possibility Maximalism (pure).
  • ¬ Truths are ND-necessary. Every truth is ND-necessary, that is, necessary under the distinctness-preserving modality.
  • ¬ Vicinity. There is a true proposition that entails the possibility of each true proposition.
  • ¬ BF. The Barcan Formula at every type. The predicate formulation closes the formula schema using lambda abstraction.
  • ¬ Boolean Completeness. Every property of entities of a relational type has a greatest lower bound in that type.
  • ¬ Countable Boolean Completeness. Every countable property of entities of a relational type has a least upper bound in that type, where a property is countable relative to a type \sigma when it injects into the finite cardinalities of properties of type \sigma; one instance for each \sigma.
  • ¬ Boolean Completeness (type t). Every property of propositions has a greatest lower bound.
  • ¬ Weakly Inextensible Comprehension. Every relation, including a proposition, is coextensive with a weakly inextensible one.
  • ¬ BF (type t). If every proposition necessarily has a property, then necessarily every proposition has it.
  • ¬ Self-Atomicity (type t). Every possible proposition is entailed by a self-atom: a possible proposition that necessarily, if true, is an atom, that is, one that entails that it is the actual world.

Definition

Proposition D.5, part 3 (p. 77): the one-object category whose arrows are all the monotone maps of \mathbb N. In every part, W_0^\ddagger is the set of finite subsets of \mathbb N and the model is ideally full: a proposition is a set of arrows whose membership depends only on the arrows’ values on some finite set of numbers (it is pinned down by that set), and an entity of a higher type is an applicative behaviour profile pinned down by a finite set in the same sense. The individuals are the natural numbers, acted on by the arrows themselves. Propositions and properties are thus about finitely many numbers and indifferent to how the arrows treat the rest. Evaluation point: the sole object, at the identity arrow.

Interpretation of Σ, fixed for this record: one designated relational constant c of type \tau=\bar\sigma t denotes \lambda\bar x\, .\,p_0, where p_0 is the proposition that the arrow fixes 0, pinned down by \{0\}; every other constant of Σ is relational and denotes the top element of its type.

A member of the group Finite-support action models on one object, which supplies this definition with the record’s settings, and the arguments marked as shared.

Fails Witnessed Possibility, No Contingency (signature Σ).

No Contingency (signature Σ) fails, since \forall\bar x\, .\,c\bar x denotes p_0, true and false at the constant map to 1. Witnessed Possibility fails for the pure formula x=\top_\tau, witnessed by \top_\tau: \Diamond(c=\top_\tau) is \Diamond\Box p_0, and \Box p_0 holds at no arrow h, since the constant map to 1 composed after h moves 0. Separated Structure fails with it, being equivalent to Possibly Witnessed Possibility. Distinctness Maximalism (signature Σ) fails by derivation, since Possibility Maximalism (pure) fails here. Whether c denotes what some closed pure term denotes is not settled, so Independence (signature Σ) is left unknown. The choice of a contingent rather than a pure denotation is deliberate: this is the only recorded model of Atomlessness in which No Contingency (signature Σ) is refuted, the others being one-object models with pure interpretations of the constants.

Fails Truths are ND-necessary.

The shift h that fixes 0,\ldots,m-1 and adds one to everything from m on is a monotone injection, so for any true q pinned down by a finite Y a monotone k with k(hy)=y on Y exists and k\circ h\in q; thus \Diamond q holds at h, while the true proposition that m is fixed is false there.

By Claude Fable 5.1 (Anthropic), prompted by Cian Dorr, 2026-09-23.

Fails Vicinity.

A true w pinned down by a finite set S contains every arrow agreeing with the identity on S, among them the monotone map equal to the identity up to M and constant at M+1 beyond it, for S\subseteq[0,M], one that collapses two numbers a\ne b outside S. The proposition \{k : ka\ne kb\} (with the natural numbers as individuals, that a and b are distinct) is true, and it is possible at no arrow that collapses them, since a collapse persists under composition, so w does not entail its possibility.

Holds Truths are two-hat necessary.

Write \mathrm{fix}_N for the arrows agreeing with the identity on the finite set N, the least true proposition pinned by N, and \delta_N for the arrows injective on N. An arrow v is in \Diamond\,\mathrm{fix}_{[n]} iff some monotone x has x\circ v fixing [n], iff v is injective on [n]; and \Diamond\delta_{[n]}=\delta_{[n]}. So \Box_{\ne}p holds iff p\supseteq\delta_{[n]} for some n, and the true proposition \{h:h(0)=0\} is not ND-necessary, since the shift m\mapsto m+1 is injective. Two-hat necessity, however, is truth: u\in\hat\Diamond\,\mathrm{fix}_{[n]} requires, for every m, a monotone v injective on [m] with v\circ u fixing [n]; injectivity of v on [m] gives v(j)\ge j for j\le m, so i=v(u(i))\ge u(i)\ge i and u fixes [n]. Thus \hat\Diamond\,\mathrm{fix}_{[n]}=\mathrm{fix}_{[n]}, every truth is two-hat necessary, and \{h:h(0)=0\} is two-hat necessary but not ND-necessary. (The verdicts this argument also establishes but does not record are derived by the engine.)

Holds Rigid Power.

Write X_0(E) for the intension k\mapsto k\cdot E. For E pinned down uniformly by a finite S_0, X_0(E) is in the domain, pinned down by S_0, and so is X_0(T) for every T\subseteq E and X_0(k\cdot E) for every arrow k. The extension at k of the power property \lambda X\, .\,\operatorname{Rigid}(X)\land X\le F is the set of rigid X with X\le k\cdot F, the bound variable untransported and the parameter transported; by the condition, for rigid F=X_0(S) it is \{X_0(T'):T'\subseteq k\cdot S\}, and transporting the extension at the identity along k gives \{X_0(k\cdot T):T\subseteq S\}, the same set, since T'\subseteq k\cdot S is k\cdot T for T:=\{s\in S:k\cdot s\in T'\}. So the power property is X_0 of its own extension, which is pinned down uniformly, hence in the domain and rigid. In these models the rigid relations are thus (a) the haecceities, (b) the properties “being pinned down by S”, which are X_0(\operatorname{Pin}(S)), and (c) the disjunctions, finite or infinite, of haecceities of entities pinned down by one finite set; the boxed form follows from No Pure Contingency.

Fails Boolean Completeness (type t).

The source (n. 92) conjectures this but does not show it. Any set F of propositions is the extension at the identity of an element of the domain at type t\to t, namely the profile \langle h,p\rangle\mapsto\{i : i\cdot p\in F\}: it is natural, independent of h and so pinned down by the empty set, and each of its values is pinned down by the pinning set of p, since i\cdot p depends only on the values of i there. A least upper bound of F under entailment is a least finitely pinned superset of \bigcup F, and it exists only if the least S-pinned superset of \bigcup F stops shrinking as the finite set S grows. So the family F of the condition has no least upper bound, and, taking pointwise negations, the family of complements has no greatest lower bound.

Fails Weakly Inextensible Comprehension.

At type e\to t, for the property of being even, which is in the domain as the constant intension \{\langle b,h\rangle : b\text{ even}\}, pinned down by \emptyset. Unpacking \operatorname{Inextensible} as in the left-to-right half of Dorr’s rigidity criterion (draft, Lemma 14, p. 7, with Lemma 13): even the unboxed matrix, evaluated at the identity, says that Y is contained in every persistent (transport-closed) B in the domain whose extension includes Y’s. For a finite N^{\prime}, the smallest such B pinned down by N^{\prime} is B_{N^{\prime}}:=\{\langle b^{\prime\prime},i^{\prime}\rangle : i^{\prime\prime}(b)=b^{\prime\prime}\text{ for some even }b\text{ and some arrow }i^{\prime\prime}\text{ agreeing with }i^{\prime}\text{ on }N^{\prime}\}, which is transport-closed and pinned down by N^{\prime}. Now let Y be coextensive with evenness and pinned down by a finite N_0; then \langle b,i\rangle\in Y for every even b and every arrow i fixing N_0 pointwise. Take the arrow i, the even b and the finite N^{\prime} that the condition provides for N_0: no arrow agreeing with i on N^{\prime} sends an even number to b. So \langle b,i\rangle\in Y\setminus B_{N^{\prime}}, and Y is not even weakly inextensible.

Fails Analytic Necessitism.

Withdrawn 2026-10-29 by Claude Opus 5.5 (Anthropic), prompted by Cian Dorr, after a trawl subagent’s report: The step from k\cdot y=k\cdot x\in X_k to Xy (or y\in X_h) by inextensibility does not follow: inextensibility bounds a rigid carrier from above, by the transports of its actual instances, and puts nothing new into its actual extension. The conclusion is false in many of the models the argument was applied to: entities fixed by every arrow, or transported injectively, can carry a rigid real number structure that is necessarily one (see analytic-necessitism-codomain-fixed and analytic-necessitism-full-continuum).

Let k be an arrow out of the evaluation object w with ka=kb for two distinct points a and b of the set the arrows act on, and let q be the set of arrows j out of w with ja\ne jb. It contains the identity, is pinned down by \{a,b\}, is symmetric (an arrow separates a from b iff its composite with a permutation of the points does), and contains no arrow j\circ k. Let \tau be tt, or tttt in the case noted below. No entity x of type \tau at w is determined by its transport along k: let y agree with x except at the arrows in q, where the top entity of the argument type of \tau is added to its value or removed from it. Then y is pinned down by a finite set along with x, is symmetric if x is, so is in the domain; it differs from x and has k\cdot y=k\cdot x, transport along k reading only the values at the arrows after k. If \mathfrak R were a rigid real number structure at w of type \tau, necessarily a real number structure, with carrier X (Background, Analysis), an instance x of X and y as above would give k\cdot y=k\cdot x\in X_k by persistence, Xy by inextensibility, and k\cdot y\ne k\cdot x by the necessary distinctness of the instances: so X has no instance. The antecedent of Analytic Necessitism holds, however, at type \tau. The propositions are infinitely many and, in the recorded instances, include a copy of the natural numbers, so by extensional fullness the entities of type tt, which include one with any set of propositions as extension at the identity, include a copy of the sets of natural numbers and so of the reals, whose order, sum, product and natural numbers are the extensions at the identity of relations in the domain; the structure is complete, every subset of its carrier being the extension of a subproperty, so \exists\mathfrak R\,.\,\operatorname{Real}_{tt}(\mathfrak R) holds at w. (Should the propositions be infinite without including a copy of the natural numbers, the same holds at type tttt, the sets of sets of propositions being Dedekind-infinite in ZF.) So Analytic Necessitism fails. No choice is used.

Holds Arithmetic Necessitism.

The numbers at a type \sigma are the instances of \mathbb N_\sigma, the least property containing \mathbf 0_\sigma and closed under \operatorname{Suc}_\sigma (Background); the numerals \mathbf 0_\sigma, \operatorname{Suc}_\sigma\mathbf 0_\sigma,\ldots are closed terms, so each denotes at every object, and transport along an arrow carries its denotation at the source to its denotation at the target. Holds □Self-atoms are atoms, □Self-atoms are strong atoms. Fails Self-Atomicity (type t).

A self-atom of any relational type at an object W is instantiated at some arrow k out of W, and its transport along k is an atom at k’s target instantiated at the identity there. The existential projection of an atom I of a relational type, the proposition \exists\bar x\, .\,I\bar x, is an atom of type t: it is in the domain, it is not bottom, and for any proposition p the entity I\land\lambda\bar x\, .\,p lies below the atom I, so is I or bottom, which puts p above the projection or disjoint from it. So the projection is a true atom at k’s target, which the condition excludes. Hence no reachable object has a self-atom, and Self-atoms are atoms and Self-atoms are strong atoms hold vacuously at every type and every reachable object, while Self-Atomicity (type t) fails at the evaluation point, the top proposition having no self-atom below it.

Holds Necessity of Second-Order Analysis.

Let v be any object reachable from the evaluation point and \mathfrak R a real number structure at v (Background, Analysis). Its completeness is tested against the subproperties of its carrier present at v, and by extensional fullness every subset of the carrier’s extension there is the extension at the identity of one of them; so the carrier, with the extensions of \le, + and \times, is a complete ordered field in the sense of the metatheory and, by Huntington’s theorem, a theorem of ZF, is isomorphic to the real numbers. For the same reason the extension of N, the least subproperty containing 0 and closed under adding 1, is its set of natural numbers, that set being the extension of a subproperty. A second-order analytical sentence A(\mathfrak R) quantifies over the relations among entities of the structure’s type at v, applied to the structure’s elements, and their extensions at the identity are all the relations on the carrier, again by extensional fullness. So A(\mathfrak R) holds at v exactly when A holds in the real numbers under full second-order semantics, which depends neither on v nor on \mathfrak R. Hence \Box\forall\mathfrak R\,.\,\operatorname{Real}_\sigma(\mathfrak R)\to A(\mathfrak R) holds when A is true of the reals and \Box\forall\mathfrak R\,.\,\operatorname{Real}_\sigma(\mathfrak R)\to\neg A(\mathfrak R) when it is false: every instance of the Necessity of Second-Order Analysis holds, and with it the Necessity of Analysis and the Non-contingency of the Continuum Hypothesis, as recorded. No choice is used.

# Extensionality ⇒ Actuality

<p class='cert'>Result — Source: Classicism (2024), Lean `Classicism.Map.extensionality_r_implies_actuality`; produced by Andrew Bacon and Cian Dorr; recorded by OpenAI Codex (GPT-6), 17 September 2026.</p>

## Premises

- **Extensionality.** At each relational type, coextensive relations are identical; include the nullary propositional case.

## Conclusion

- **Actuality.** There is a true proposition that entails every true proposition.

## Proof

Use $\top$ as the witness. Every true proposition is identical to $\top$ by the Fregean Axiom, so $\top$ entails every truth.

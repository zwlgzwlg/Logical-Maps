# □Vicinity ∧ □Weakly Inextensible Comprehension ⇒ □Actuality

<p class='cert'>Result — Source: Misc.; produced by Christopher Sun (the unboxed result), 27 September 2026; Claude Opus 5.5 (Anthropic), the boxed form; recorded by Claude Opus 5.5 (Anthropic), 27 September 2026.</p>

## Premises

- **□Vicinity.** Necessarily, there is a true proposition that entails the possibility of each true proposition.
- **□Weakly Inextensible Comprehension.** Necessarily, every relation, including a proposition, is coextensive with a weakly inextensible one.

## Conclusion

- **□Actuality.** Necessarily, there is a true proposition that entails every true proposition.

## Proof

The proof of vicinity-and-weakly-inextensible-comprehension-imply-actuality uses no optional hypothesis and a single closed instance $\phi$ of Weakly Inextensible Comprehension (type $t\to t$), so Vicinity $\land\,\phi\to$ Actuality is a theorem of C. Necessitate it and apply K to $\Box$Vicinity and $\Box\phi$, the latter an instance of □Weakly Inextensible Comprehension.

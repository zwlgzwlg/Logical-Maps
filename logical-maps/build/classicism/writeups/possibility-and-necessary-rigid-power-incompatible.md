# Possibility Maximalism (pure) ∧ □Rigid Power ⇒ ⊥

## Premises

- **Possibility Maximalism (pure).** Every closed pure sentence consistent with C is possible.
- **□Rigid Power.** Every closed instance of Rigid Power is necessary. Box the entire object-variable closure; retain the same type range and other schema side conditions.

## Conclusion

- **⊥.** These premises cannot all hold together.

## Proof

Rigid Power fails at type $e\to t$ in finite-support-pair-injections-or-collapses, a model of C, so the negation of that closed pure instance is consistent with C. Possibility Maximalism (pure) makes the negation possible, while □Rigid Power says the instance is necessary.

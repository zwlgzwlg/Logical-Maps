# No Pure Contingency ∧ Vicinity ⇒ □Vicinity

<p class='cert'>Result — Source: Misc.; produced by Cian Dorr, suggestion of 27 September 2026; recorded by Claude Opus 5.5 (Anthropic), 27 September 2026.</p>

## Premises

- **No Pure Contingency.** Each closed sentence of the pure language, if true, is necessary. This is a sentence schema, not a quantifier over propositions.
- **Vicinity.** There is a true proposition that entails the possibility of each true proposition.

## Conclusion

- **□Vicinity.** Necessarily, there is a true proposition that entails the possibility of each true proposition.

## Proof

Every closed instance of Vicinity is a closed sentence of the pure language, since the principle is stated with object-language quantifiers and contains no nonlogical constant. Given Vicinity, each instance is true, and No Pure Contingency makes it necessary. Type ranges stay outside the box.

## Premises

- **□Tame Rigidity.** Every closed instance of Tame Rigidity is necessary. Box the entire object-variable closure; retain the same type range and other schema side conditions.
- **□Weak Rigid Comprehension.** Every closed instance of Weak Rigid Comprehension is necessary. Box the entire object-variable closure; retain the same type range and other schema side conditions.

## Conclusion

- **□Rigid Comprehension.** Necessarily, every relation, including a proposition, is coextensive with a rigid one.

## Proof

The argument of Tame Rigidity + Weak Rigid Comprehension ⇒ Rigid Comprehension uses the premises only at the conclusion's type tuple and nothing beyond C. So for each closed instance, C proves the conditional from the corresponding instances of Tame Rigidity and Weak Rigid Comprehension to the instance of Rigid Comprehension. Necessitate that theorem and apply K with the boxed premise instances. Generalization over the admitted types is metalinguistic; no type quantifier is placed inside the box.

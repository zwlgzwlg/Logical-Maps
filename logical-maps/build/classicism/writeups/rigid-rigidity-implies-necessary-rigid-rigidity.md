# Rigid Rigidity ⇒ □Rigid Rigidity

## Premises

- **Rigid Rigidity.** Being rigid is a rigid property of relations, including propositions.

## Conclusion

- **□Rigid Rigidity.** Every closed instance of Rigid Rigidity is necessary. Retain the same type range.

## Proof

Each closed instance of Rigid Rigidity is a conjunction of persistence and inextensibility, both of the form $\Box\phi$. By 4 each conjunct is necessary, so the instance is.

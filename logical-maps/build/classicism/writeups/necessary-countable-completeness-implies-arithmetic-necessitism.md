# □Countable Boolean Completeness ⇒ Arithmetic Necessitism

## Premises

- **□Countable Boolean Completeness.** Necessarily, every countable property of entities of a relational type has a least upper bound in that type, with countability relative to a type $\sigma$ as in Countable Boolean Completeness; one instance for each $\sigma$.

## Conclusion

- **Arithmetic Necessitism.** Given that necessarily zero is not a successor and successor is injective on numbers, the numbers at $\sigma$ form a rigid property with necessarily distinct instances. One sentence for each type $\sigma$.

## Proof

Fix $\sigma$, $\nu=(\sigma t)t$ and $\rho=\nu t$. Goodsell’s numerical-haecceity argument (Lemma 8) proves the discharged C theorem $\mathrm{CBC}_{\sigma,\rho}\to\operatorname{WeaklyInextensible}(\mathbb N_\sigma)$. Necessitate that theorem and apply K to obtain $\Box\mathrm{CBC}_{\sigma,\rho}\to\Box\operatorname{WeaklyInextensible}(\mathbb N_\sigma)$, exactly the native inextensibility clause including its leading box. The unconditional number-persistence theorem (Lemma 3), itself necessitated, supplies native persistence. Under the Arithmetic Necessitism guard $\Box I^*_\sigma$, Lemma 4 gives necessary distinctness of current numbers. Discharging that guard proves the instance at every $\sigma$.

## Notes

A recovered composition of existing arithmetic lemmas. The extra box on CBC licenses all-future weak inextensibility. Current CBC alone cannot be necessitated while it remains an undischarged assumption; this proof does not establish current CBC implies Arithmetic Necessitism.
